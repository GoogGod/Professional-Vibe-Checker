# eval — Vibe Check (оценка агента)

Комплект для честного сравнения: агент **с пакетом** (промпт + скиллы + база) против того же агента **без пакета**. Отвечает на вопрос «становится ли агент быстрее ориентироваться и решать надёжнее?» — с предзарегистрированными метриками и изоляцией прогонов.

## Файлы комплекта

- `PROTOCOL.md` — **читать первым**: гипотезы, метрики, правила честности.
- `checklists/isolation.md` — как обеспечить чистоту прогонов (Artex и не только).
- `templates/run-log.md` — лог одного прогона (front matter парсится скриптом score.py).
- `templates/task-pack.md` — единый текст задачи для обеих веток.
- `templates/final-report.md` — итоговый отчёт по серии.
- `scripts/new_run.py` — создать каркас прогона (каталог + лог из шаблона).
- `scripts/score.py` — агрегация: `python -X utf8 scripts/score.py --runs <dir> --out results`.
- `examples/` — демонстрационные логи (score.py можно прогнать прямо на них).

## Быстрый старт

```powershell
# 1) Зафиксировать версию пакета (коммит) и подготовить задачи
# 2) Каркас прогона:
python -X utf8 eval\scripts\new_run.py --batch pilot-01 --task web-01 --branch A
# 3) Прогнать задачу по чек-листу; заполнить лог и метрики
# 4) Сводка:
python -X utf8 eval\scripts\score.py --runs eval\runs --out eval\results
# 5) Отчёт по шаблону templates/final-report.md
```

## Правила (кратко)

- Метрики предзарегистрированы (`PROTOCOL.md`) и не меняются в ходе серии.
- Ветка B не видит пакет; ветка A не видит чужие прогоны; база заморожена на серию (запись — в карантин).
- Сохраняем ВСЕ прогоны, включая провалы; `invalid` — только с причиной.
- `slop_flags` (фейковые флаги) — обязательная метрика; ожидание для A — 0.
- Эталонные флаги — вне репозитория, в логах только `flag_confirmed: true|false`.
