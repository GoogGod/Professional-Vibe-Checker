# Red Team Agent Kit — модуль опыта для LLM-агентов

Переносимая «рабочая память» CTF/Red Team агента: системный промпт, скиллы, база знаний с петлёй самообучения (hermes). Работает в любом harness и **не требует внешних инструментов** — только чтение файлов и CLI.

## Установка за 4 шага

### 1. Скачай релиз
**Releases** → `redteam-pack-<версия>.zip` → распакуй, например в `C:\tools\redteam-kit`.
Для разработки — `git clone`; точка входа для агента тогда [`AGENT.md`](AGENT.md).

### 2. Добавь скиллы в harness
Скиллы — это каталоги вида `<имя>/SKILL.md`.
- **Harness с файловыми скиллами:** скопируй каталоги из `skills/` релиза в каталог скиллов harness'а, **не переименовывая** (привязки идут по имени каталога).
  - Artex (Windows): `<корень установки>\skills\` (например `C:\tools\skills\`); после копирования перезапусти сессию.
  - Из клона репозитория это делает `tools/sync_package.ps1 -SkillsTarget "<каталог скиллов>"` (флаг `-IncludeLibrary` добавит категорийную библиотеку `ctf-web`, `ctf-crypto`, ...).
- **Harness без файловых скиллов** (или не хочешь устанавливать): пропусти шаг — модуль работает как обычная папка, см. шаг 3б.

### 3. Добавь системный промпт
- Содержимое `system-prompt.md` → в системный промпт / роль агента (в настройках harness'а).
- **3б. Если системный промпт нельзя изменить** — первым сообщением агенту: «Рабочая папка `<путь к распакованному релизу>`. Начни с `START-HERE.md` в ней и следуй ему». Модуль подключится сам: скиллы и базу агент читает напрямую как файлы, инструмент `Skill` не нужен.

### 4. Дай задачу
Всё. Дальше агент работает сам:
- **до задачи:** `skills/ctf-router/SKILL.md` → 1–2 релевантных скилла → поиск по базе (`index.md`);
- **во время:** методология «триаж → разведка → гипотезы → минимальный PoC → верификация»; выдумывать флаги запрещено;
- **после:** записывает урок в `lessons/` + строку в `index.md` — **только если урок важный и переносимый** (пустой writeback — норма). Это и есть петля hermes: база растёт от каждой задачи.

## Обновление
Скачай новый релиз и замени каталог. Имена скиллов стабильны — привязки harness'а не ломаются. Что изменилось — `package/CHANGELOG.md`.

## Свойства
- Внешние инструменты (web-поиск и т.п.) не требуются; всё локально (Windows + WSL + PowerShell — детали в промпте).
- Генерация значений флагов запрещена; публичный пакет значений не содержит (`tools/check_package.ps1` сканирует всё; CI проверяет каждый PR). Локально значение можно фиксировать с пометкой «не ответ для других задач».
