# Knowledge Base — переносимая база знаний

Общая база наработок агентов (Hermes-стиль): всё, что найдено и придумано в задачах, сохраняется здесь и помогает следующим агентам. Является частью переносимого пакета — начинай с `START-HERE.md`.

## Структура

- `START-HERE.md` — инструкция по развёртыванию и правила пакета;
- `system-prompt.md` — системный промпт агента;
- `skills/` — скиллы пакета (agentskills.io-формат);
- `index.md` — реестр записей;
- `lessons/` — уроки и разборы кейсов;
- `tactics/` — чек-листы и тактики по темам;
- `toolbox/` — рабочие скрипты и заготовки;
- `flags/` — только политика хранения флагов.

## Железные правила

1. **Генерация значений флагов запрещена** (в том числе «для отвода внимания»); публичная база значений не содержит; локальная копия урока может хранить значение с пометкой «не ответ для других задач».
2. **Обезличенность**: названия конкретных соревнований и площадок не используются; кейсы описываются по технике.
3. **Переносимость**: все пути внутри записей — относительные (относительно этого каталога).
4. **Архив — не текущая задача**: записи описывают прошлый опыт и не относятся к текущему заданию.
5. Секреты/PII в базу не попадают.

## Ритуал (для агента)

- Перед задачей — поиск по `index.md` и файлам базы; после задачи — важные записи в `lessons/` + строка в `index.md` (пустой writeback — норма); скрипты → `toolbox/`; повторяющиеся тактики → `tactics/`.
- Подробности и шаблон — в скилле `hermes-knowledge-loop`.
