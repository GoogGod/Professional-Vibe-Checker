# library — библиотека категорийных скиллов

Наследие: локально накопленная библиотека CTF-скиллов (не авторства пакета; в файлах сохранены лицензионные заголовки, напр. MIT). Включена, чтобы пакет был **самодостаточным** и знание не терялось при переносе.

## Состав (`skills/`)

- Категорийные методички: `ctf-web`, `ctf-crypto`, `ctf-reverse`, `ctf-pwn`, `ctf-forensics`, `ctf-osint`, `ctf-misc`, `ctf-malware`, `ctf-ai-ml`, `ctf-writeup`, `solve-challenge`.
- Вспомогательные (поведение/коммуникация): `os-*`.

Каждый скилл — `SKILL.md` + `references`-файлы по темам (итого ~140 файлов).

## Правила использования

- **Точечно**: открывать только нужные категории/файлы, не грузить всё сразу.
- Это **дополнение**, не замена маршрутизации: порядок работы задаёт `skills/ctf-router`.
- Материалы содержат примеры из **публичных** чужих разборов (плейсхолдеры, не реальные флаги). Не переносить примеры в выводы о текущей задаче; архив ≠ текущая задача.
- Редактировать аккуратно: это наследие; при улучшении — пометки `[update: дата]`.

## Примечание о сборке

Включена свежая редакция библиотеки (единый экземпляр). Существовал более старый локальный снимок — в пакет не включён: содержимое идентично, отличались только переводы строк.
