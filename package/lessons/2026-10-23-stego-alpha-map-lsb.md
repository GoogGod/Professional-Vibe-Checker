# Стего: альфа-канал как карта + LSB только в отмеченных пикселях

- **Дата:** 2026-10-23 (полевой solve, hard)
- **Категория:** стего / PNG / LSB
- **Ключевые слова:** alpha channel, map, LSB, marked pixels, RGBA, zsteg-слепая зона

## Механика

PNG RGBA: альфа-канал константа (255) всюду, кроме N аномальных пикселей (значение 254 или иное). Аномалия — не данные, а **карта**: полезная нагрузка — LSB-биты RGB-каналов ровно отмеченных пикселей, в порядке scan (row-major), биты interleaved по каналам R→G→B, сборка MSB-first.

Почему zsteg/stegseek слепы: они читают плоскости целиком — здесь LSB фона это шум, а 102 «полезных» пикселя тонут в 1М остальных.

## Детект (3 команды)

```python
px = np.asarray(Image.open(f).convert("RGBA"))
print(np.unique(px[:,:,3], return_counts=True))  # аномалия видна мгновенно
```

- гистограмма альфы: ровно 2 значения, одно на порядки реже → карта;
- число отмеченных N: payload = N×3 бит = N×3/8 байт — сверить с ожидаемой длиной флага (38 байт = 102 пикселя);
- если N×3/8 ≈ длина флага — это оно, дальше только порядок.

## Декод

`toolbox/alpha_lsb.py` — авто-детект аномальной альфы + батарея вариантов (порядки row/col, каналы RGB/BGR/моно, MSB/LSB-first) + скоринг по printable-ratio + `--expect "префикс{"` самопроверка (exit 0):

```
python3 alpha_lsb.py img.png --expect "CTF{"
```

Полевой прогон: 1024×1024 PNG, 102 отмеченных → 38 байт текста, победитель row/RGB/msb ratio 1.00, префикс сошёлся с первого прогона.

## Обобщение (проверять в этом порядке)

1. Любой «почти константный» канал/подмножество — кандидат в карту: alpha=254, редкий цвет в палитре, пиксели с редким цветовым признаком.
2. Карта + LSB — механизм «читай не всё, а отмеченное»: побитовая плотность низкая, зато детерминированная.
3. Если N отмеченных ×3 бит сильно больше флага — внутри может быть префикс-заголовок или координатное кодирование (сначала ASCII-гипотеза, потом позиционное).
