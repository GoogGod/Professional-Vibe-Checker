# Форензика: следы ALPC/IPC в памяти (Puzzle-подобный)

Суть: большой memory dump (vmem 2ГБ) содержит не фрагменты файлов, а остатки
межпроцессных коммуникаций Windows (ALPC) — их надо эксплуатировать как источник
информации.

## С чего начинать
1. Волатити/volatility3: pstree, pslist. Определить процесс-«брокер».
2. Искать специфичные объекты ядра (ALPC ports, IPC). В задачи часто зашита
   переписка процессов через LPC/ALPC.
3. В дампе искать сигнатуры сообщений: заголовки с длиной, ID соединения,
   данные с флагом/ключом в «остатках».

## Ключевые приёмы
- `vol.py -f dump.vmem windows.pstree` — дерево процессов.
- `windows.modules` / `windows.handles` — какие порты/мьютексы/события созданы.
- Поиск по байтам-строкам: флаг обычно имеет префикс платформа{...}; обломки
  возникают при перезаписи буферов.
- Если задача про «картинки» (pixels) — вероятно, из данных выделяли изображение
  (например, QR/ASCII-art), собираемое из остатков буферов.

## Итог
- Разбирать «остатки» (remnants) — не только файлы, но и IPC-буферы, строки,
  хэши, окна/экранные буферы.
- Проверять флаг целиком; кодировка флага в images (QR) — тоже частый ход.
