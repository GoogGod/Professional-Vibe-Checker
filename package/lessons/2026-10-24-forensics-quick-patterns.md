# Урок: быстрые паттерны easy-форензики (pcap / evtx / fs / memory)

Дата: 2026-10-24 · Категории: forensics (консолидация 6 полевых кейсов, все решены) · Уровень: easy

Один общий вывод: easy ≠ «сразу флаг». Правильный первый приём (агрегация / экспорт объектов / дифф / карвинг) даёт ответ за минуты; неправильный — часы ручного перебора.

## Паттерны

1. **pcap под DDoS-шумом**: агрегируй кортежи (src, method, uri) c подсчётом — тысячи однотипных запросов ботов тонут, единичные запросы атакующего всплывают. Флаг часто в query-параметре (например `login?...`); декой-эндпоинт типа `/get_flag` вернёт приманку — не ведись.
2. **MITM-pcap с доминирующим TLS**: сначала `tshark --export-objects http` — «важные файлы» из условия это HTTP-объекты. OCSP-блобы (даты в DER) — приманки. Флаг может быть напечатан на картинке → tesseract; psm7 теряет `_` (превращает в пробел) — сверяй с psm13/makebox.
3. **Covert channel в UDP-портах**: если полезной нагрузки в пакетах нет, а порты берутся из перечислимого диапазона — диапазон кодирует порядок, соседнее поле — данные (пример: `srcport-30000` = индекс байта, `32768-dstport` = значение байта). Имя файла может дезинформировать. Детект: перечислимый диапазон = порядок, соседнее поле = payload.
4. **Стего внутри pcap**: ищи пары почти одинаковых объектов (v1 → v2) и диффуй; отличие только в LSB первого столбца пикселей = биты по столбцу. Если после base64-decode получается «шифртекстоподобный» мусор — сначала проверь **кастомный base64-алфавит** (длины ключа и данных, кратность 64, стандартный алфавит не дешифрует), и только потом гадай шифр.
5. **ext4 «файлы удалены, папки остались»**: `istat` показывает size=0/пустые extents → `icat` бесполезен. Карвинг unallocated: `blkls` → `binwalk` (gzip-потоки с FNAME-именами) → распаковка python-zlib по смещению (`dd bs=1` на мегабайтных кусках виснет насмерть). Цепочки кодировок (base32→base64→tar→gz) разворачивай питоном в один скрипт. Приманка вида `Not<формат>{...}` подтверждает формат настоящего флага.
6. **evtx — сопоставления полей лежат в одном событии**: пример — `DeviceName \Device\HarddiskVolumeX` ↔ `DriveName \\?\Volume{GUID}` в одном EventData (Microsoft-Windows-Ntfs, EventID 98). python-evtx + `grep -B/-A` по контексту. Примета: GUID-форма DriveName = внешний том, `C:` = системный.
7. **Дамп памяти (.vmem/raw)**: `grep -aob` по сырым байтам часто быстрее volatility; UTF-16LE-паттерн через bash-аргумент невозможен (NUL обрезает строку) — python. Строки сигнатур антивируса в дампе = шум, не артефакты. Метаданные редакторов восстанавливают утраченное: статус-бар notepad («Стр 1, стлб N») = длина текста.

## Сквозные morals

- Первый вопрос к артефакту: «что здесь Noise, а что Signal» — и инструмент, который их разделяет (uniq -c, diff, binwalk, grep -aob).
- Приманки (decoy) — нормальная часть easy-задач: они подтверждают формат, но не ответ.
- Сложные цепочки (кодировки/архивы) — один python-скрипт, а не конвейер из dd/shell.
