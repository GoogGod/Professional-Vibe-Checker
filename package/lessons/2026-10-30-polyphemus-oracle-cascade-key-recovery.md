# Polyphemus: каскадное восстановление ключа через парный оракул (crypto hard, платформа)

- Дата: 2026-10-30 · Категории: crypto, блочный шифр, оракул · Уровень: hard ✓ решена
- Сервис: `[instance]`, Python-файл `polyphemus.py` (кастомный 16-раундовый блок-шифр).

## Суть шифра
- `decrypt_block(key, block, iv)`: XOR блока с ключом → 16 раундов → XOR с ключом.
- Раунд: `F(R, k_i) = SBOX[GF(2^8) полиномиальное произведение байтов R с k_i]`, `k_i = key[i] ^ iv[i]`.
- SBOX: `random.seed(1234)`, 8 перетасованных колонок байтов.
- Симметричность: расшифровка = шифрование; известное тождество `D(key, 0, key) = 0`.
- Ключ генерируется заново на каждое соединение → вся атака + сабмит строго в одном соединении.

## Ключевые наблюдения
1. **Диффузия IV**: при фиксированном блоке изменение `iv[0]` меняет только правую половину выхода; при `iv[0..k]=key[0..k]` изменение `iv[k+1]` меняет только правую половину для чётного k, левую — для нечётного.
2. **Парный тест кандидата**: если префикс `key[0..k-1]` верен, кандидат h для байта k проходит iff `out_half(iv[k]=h, iv[k+1]=0) == out_half(iv[k]=h, iv[k+1]=1)` (половина — по чётности k). Истинный байт всегда среди 1–3 проходящих.
3. **Последний байт**: `D(key,0,key)=0` → `oracle(iv)=0` при `iv=key`; кандидатов может быть ≥1 → финальная проверка на случайных (iv, block) парах против локальной референсной реализации.
4. **Сдвиговая неоднозначность**: одна кривая `phi(d)=C xor SBOX[P(s xor d)]` допускает поглощение любого s в коэффициенты → одиночная кривая не восстанавливает ключ; нужен относительный каскад (сравнение соседних iv), а не абсолютный сдвиг.

## Атака
- Каскадный DFS: для k=0..14 перебрать h∈[0,256), парные запросы (iv[k+1]=0/1), собрать проходящих; ветвление по кандидатам (1–3 уровня).
- Объём: ~512 запросов на байт + 256 на последний → ~8000 запросов на соединение. Сервер держит: батчи по 2048 запросов отвечают за <1 с (0.4 мс/запрос).
- Сетевая реализация: единый буфер, слать все CT-строки разом, парсить `dec: <hex>` подряд; промпт `Enter hex to decrypt, or press Enter to continue.`; пустая строка → `Enter key (hex):` → ключ → флаг.
- Валидация: сначала синтетика (свой ключ, MATCH: True), потом живой сервер.

## Уроки
- Оракул «decrypt с выбранным IV» при кастомном шифре = восстановление ключа: ищи диффузию изменений IV по половинам.
- Парные запросы (соседние IV) снимают сдвиговую неоднозначность кривой — не пытайся решать одиночную кривую.
- Эфемерный ключ на соединение → планируй односоединённый протокол «все запросы + сабмит».
- Батч вместо round-trip: 8000 запросов в одном буфере — секунды; по одному — минуты и риск таймаута.
- Всегда валидируй атаку на синтетике до боевого прогона.
