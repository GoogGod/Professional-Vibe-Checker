# Lamport JWT: восстановление глобального ключа по множеству токенов (ClimaGlow, платформа/платформа hard)

Дата: 2026-10-30. Категория: Web + Crypto (hard). Сервис: [instance] (ClimaGlow).

## Схема
- Кастомный «Lamport JWT»: `payload` → `md5(json.dumps(payload, separators=(",",":")))` → 128 бит → `signature[i] = key[i][bit_i]` (база85 16-байтовых половин). Проверка: `md5(signature_piece) == hash(key[i][bit])`.
- Ключ приватный глобальный (один на всех пользователей, файл instance/secret_key.json), подпись детерминированная.
- Токен: JSON `{"header":...,"payload":...,"signature":[...]}` в base85, в куке `token="..."` (двойные кавычки обязательны — без них 401).
- Флаг отдаётся в `/monitor` при `role=="admin"` (feature_flag из env FLAG).

## Атака
Набрать токены многих пользователей (40 шт.: register с username/email/password → login → Set-Cookie token). В каждой из 128 позиций увидеть обе половины пары (проверка: 0 позиций с одним значением, 256 уникальных значений). Собрать пары `pairs[i]={v0,v1}` → полный приватный ключ.

Форджинг: target payload = любой юзерский payload с `role="admin"`; для позиций, где бит md5(target) != бит md5(original), подставить вторую половину пары; перекодировать в base85, положить в куку с кавычками → `GET /monitor` → флаг (значение конкретной задачи, НЕ ответ для других задач: `[FLAG]`).

## SSRF-обход для чтения файлов (вторично, но было ключевым)
- `/admin/device/check?url=` доступен ЛЮБОМУ авторизованному (валидация `_is_valid_health_url` = True всегда).
- `file:///proc/self/cwd/app.py` читает исходники, хотя `/proc/**` в blacklist: `os.path.realpath("/proc/self/cwd/app.py")` превращается в `/<рабочий>/app.py` и НЕ попадает в blacklist. Против `instance/secret_key.json` защита отдельная (сравнение realpath с secret_key_real_path → 403), но с восстановленным ключом не нужна.

## Урок
Если самодельная схема подписи детерминированная и ключ глобальный — собери подписи многих пользователей: в позициях «проявится» обе половины ключа. Сначала проверь покрытие пар (0 позиций с одним значением = ключ восстановлен). Не нужно взламывать хеш: J обычная подмена половин. Также: исходники читаются через SSRF через `/proc/self/cwd` — blacklist по realpath обходится, потому что realpath «нормализует» путь в разрешённый рабочий каталог.
