# 2026-11-01 — Изображение-«пазл»: жадная сборка кусков по краям

Источник: задача с платформы — матрёшка: zip → вложенные файлы →
изображение, разрезанное на куски с белыми разрезами. Задача не доведена агентом,
но методика валидна.

## Суть
- Куски: пиксели-копии без вращения, между ними белые разрезы.
- Подход: найти белые линии (строки/столбцы полностью белые) → определить сетку кусков;
  затем жадная сборка: подбор соседа по максимальной корреляции краёв
  (сравнение пограничных столбцов/строк каждого куска со всеми остальными).

## Реализация (Windows-Python, без WSL)
- `numpy` + `PIL`/`cv2`; поиск белых линий: `(img == 255).all(axis=1/0)`.
- Корреляция краёв: `np.sum(edge1 == edge2)` — выбирай max.
- Для больших наборов — предрасчёт пары «край → кусок» и жадный путь без повторов.

## Ошибки среды (на этой машине)
- WSL есть; для пазлов обычно достаточно Windows-Python (numpy/PIL). Если нужен
  редкий пакет — pip с `--break-system-packages` (в WSL) или запрос оператора на apt.
- В PowerShell НЕТ `||` (Bash): `head -n 300` / `||` — только отдельными командами;
  пиши скрипт-файл через Write и запускай `python f.py`.
