# Миск: TOCTOU race в граф-вычислителе (compuuuter)

Суть: HTTP-сервис принимает «граф» узлов (Node), вычисляет результат по хэшам
и возвращает бинари посчитанного выражения. Гонка: мутировать вход на фоне
вычисления — результат посчитается уже с подменёнными значениями.

## Механика
- API: POST /graph → JSON: nodes (id,value,op), edges. Значения узлов считаются
  по ссылкам (hash) — кэш/сравнение узлов.
- Уязвимость: при наличии двух запросов к одному узлу (или hash-коллизии) значения
  «проскакивают»; нет блокировки на чтение/запись (TOCTOU: time-of-check vs
  time-of-use).

## Эксплуатация
- Отправлять «странные» графы: циклы, само-ссылки, недопустимые бинарные операции.
- Перебирать последовательности запросов (два параллельных) на один узел,
  чтобы один запрос читал старое, другой — новое значение (race).
- Ловить результат: если значение узла стало неожиданным — вероятно, в ответе
  появится часть флага или целочисленный код (little-endian декод).

## Итог
- Проверять «графовые» сервисы на гонки: hash-based сравнения узлов,
  повторные вычисления, отсутствие атомарности; часто хватает двух запросов.
