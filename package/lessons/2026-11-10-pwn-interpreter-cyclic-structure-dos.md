# PWN: OOB-индексация + флип тегов в интерпретаторе → RCE
- Дата: 2026-11-10 · Категория: pwn · Статус: **решено** (RCE подтверждён локально и удалённо)
- Результат: полная цепочка RCE — произвольное чтение/запись, PIE- и stack-утечки,
  ROP `execve("/bin/sh")`; флаг `[FLAG]` получен на `[instance]`.

## Уязвимость
- Чтение элемента и вложенные lvalue-присваивания проверяют границы; верхнеуровневое присваивание
  `arr[idx] = val` вычисляет `begin + idx * sizeof(Value)` БЕЗ проверки `idx < size`.
- Значение `Value` — структура с тегом варианта на `+sizeof(ptr)`; при присваивании целого,
  когда тег уже 0, выполняется чистая 8-байтовая запись без сброса состояния.

## Heap-громминг
- Буферы соседних массивов выделяются с шагом `sizeof(chunk) % sizeof(Value) = 8`:
  OOB-слоты одного массива выравниваются на теги и данные соседнего.
- Освобождение заранее подготовленных парных чанков заполняет tcache/fastbin нужных размеров,
  чтобы массивы-жертвы выделились подряд.

## Флип тегов и утечки
- Значение с гарантированным NUL-байтом хвоста позволяет флипнуть тег соседнего слота:
  слот становится int64_t и утекает указатель на объект-массив.
- Через OOB-запись указателя на `obj - 16` читается vtable (утечка базы PIE);
  далее `base + offset(__environ)` утекает стек окружения.

## Произвольная запись
- Поддельный `ArrayInstance` размещается внутри собственного буфера; перенаправление ссылочного
  слота на него + управление его `_M_start` даёт произвольную 8-байтную запись.

## ROP (stack pivot)
- NUL-заполненный строковый буфер хранится с тегом 0, чтобы деструктор не освободил его,
  а байт тега оставался 0 — в него пишется ROP-цепочка.
- Поиск на стеке ниже `env` находит адрес возврата цикла интерпретатора; обнуление соседнего
  слова и запись `pop rsp; ret` + адреса буфера в «мёртвые» нулевые поля объекта-программы
  позволяют перезаписать адрес возврата на `add rsp, N; ...; ret` и спивотнуть на цепочку.
- Цепочка: `pop rdi` → `/bin/sh\0`; `pop rsi` → 0; `pop rdx` → 0; `pop rax` → 59; `syscall; ret`.
- Теги сбрасываются, чистый выход; флаг `[FLAG]`.

## Верификация
- Локально: 10/10 успешных запусков; удалённо: флаг получен на `[instance]`.

## Урок
- Для интерпретаторов: инвентаризация всех путей присваивания (с проверками и без) — базис
  для доказательства primitive, лишь затем impact.
- Ровность размера `Value` и тег на `+sizeof(ptr)` превращают OOB-индексацию в детерминированный
  arbitrary write.
- «Мёртвые» поля объектов можно использовать как склад ROP-предикатов без ломки структур.
- Флаг → [FLAG]; хост/порт → [instance]; без имён площадок и путей.
