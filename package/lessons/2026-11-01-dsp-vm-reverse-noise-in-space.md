## Что уже установлено (промежуточные результаты)
1. В kernel есть функция sub_402140 — НЕ FM-демод, а **band-pass фильтр 300–3300 Гц + децимация /5**.
2. Код исполняется под VM (диспетчер с BAD_OPCODE-ошибками): ищи диспетчер через Xrefs
   на строку `BAD_OPCODE`, декомпилируй цикл VM — там распознаются опкоды-«инструкции».
3. Символы в сигнале: используй спектрограмму/автокорреляцию для периода символа и синхронизации.
4. «Нуль удобный»: при декодировании сигнала фильтр/нормализация может делать нулевые
   сэмплы удобными — проверь, не отбрасывается ли часть информации (например, ноль = логический 0
   или состояние).
