# Форензика: Android APK + sealed-prefs (GhostVector / Sealed Prefs)

Суть: актуальная мобильная форензика — приложение с «запечатанными» (sealed)
SharedPreferences: данные шифруются/подписываются, но при декомпиляции DEX
можно восстановить логику и расшифровать.

## Истории
- APK содержит `sealed_prefs` (файл, зависящий от ключа из кода).
- Без устройства/эмулятора — реверс DEX + написание эквивалентного расшифроватора.

## Шаги
1. apktool распаковка: assets + res + smali.
2. jadx: найти классы работы с prefs (SealedPreferences, пароль, алгоритм).
3. Если шифрование = XOR/stream (SHA256 ключ) — восстановить ключ из известных
   пар (plaintext/cipher) или из статической константы.
4. Расшифровать флаг на хосте.

## Итог
- sealed_prefs ≠ безопасность, если логика в DEX. Любой секрет в APK можно
  восстановить: искать ключи, iv, алгоритм в коде.
