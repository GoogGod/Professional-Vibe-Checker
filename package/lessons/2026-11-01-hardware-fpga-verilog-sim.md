# 2026-11-01 — Hardware/FPGA: Verilog-нетлист, iCE40 и симуляция

Источник: задача с платформы — НЕ доведена.

## Сюжет
- Дана прошивка/нетлист на Verilog (`g_vlog.v`, «simchip» + «21» — образ FPGA).
- Описание задачи: «Пурпурный флейтист играет… Три колыбельные на древнем языке»
  → три «колыбельные» = три блока ROM/LUT/песни в схеме (например, `SB_RAM40_4K`-блоки).

## Ключевые приёмы
1. **Идентификация таргета**: модули `SB_RAM40_4K`, `SB_IO`, `SB_GB` — Lattice iCE40
   (IceStorm). Это значит: для симуляции нужны библиотечные примитивы iCE40.
2. **Ошибка «Unknown module type: SB_RAM40_4K»** → подключи библиотеку примитивов
   (ice40 cells / `-l ice40.lib`), либо заменяй SB_RAM40_4K на `$readmemh`-память.
3. **Симуляция**: `iverilog`/`yosys` (в WSL недоступен на этой машине — ставь на Windows
   или используй `icarus` вне локальной сети), `simchip`-утилита эмулирует поведение.
4. **Как вытащить логику**: если нет готового топ-модуля — ищи `sp4_r_v_b_12` и т.п.
   (сетка регистров/конвейеров) и Init-данные (`INIT_6`/`INIT_7` — содержимое LUT/RAM).
   Это часто и есть «древний язык».
5. **Проверка валидности**: если в логике есть «Possibly valid» / «Definitely invalid» —
   критерий для сплита состояний (карта разрешённых зон) — ключ в самой карте.

## Системные ошибки (эта машина)
- WSL есть; для iverilog/yosys удобнее использовать его (`wsl bash -lc "iverilog ..."`).
  Ошибки прошлых сессий — из-за неверных вызовов (localhost и адрес хоста, UTF-16).
- `grep` в PowerShell нет → `Select-String` / Grep-тул.
- `Format-Hex -Count` не существует → читай HEX файлами (py) либо `Format-Hex -MaximumSize N`.
- read `knowledge-base/local/index.md` (без `data/`) — правило: всегда проверяй полный путь
  относительно рабочей папки сессии `[archive]/conv-NN`.
