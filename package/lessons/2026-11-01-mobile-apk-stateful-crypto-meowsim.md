# Мобильная форензика: APK + SharedPreferences + SQLite + «квантовый кот»

Суть: Android-приложение хранит состояние в SharedPreferences (XML) и SQLite;
часть логики «крипто» находится в самом приложении (реверс DEX).

## Шаги
1. Распаковать APK (apktool д/jadx). Посмотреть AndroidManifest: activity'и,
   цели, экспортированные компоненты.
2. Найти файлы данных: `shared_prefs/*.xml` и `databases/*.db` (SQLite).
3. Изучить DEX: алгоритм ключа/шифрования (часто state-функция на SHA256/stream XOR).
4. Установить эмулятор/устройство с xposed? Проще: запустить приложение локально
   (adb/Android Studio) и смотреть, как оно создаёт/меняет состояние.
5. Брутфорс параметра «стабильности» (если ключ зависит от нестабильного значения)
   с проверкой на известном формате флага/результата.

## Типичные находки
- Имя пакета в Manifest; targetSdk; BOLT: io flag.
- SharedPreferences: `{"box_state": ...}`; SQLite таблица `box` с колонкой `state`.
- Схема: `flag_xor = sha256(state + salt)` → восстановление по формату.

## Итог
- Декомпиляция DEX + чтение app-данных (prefs/db) быстро даёт логику.
- Если алгоритм «квантовый»/нестабильный — брутфорс малого пространства параметров
  с проверкой выхода (наличие '{' — '}' / известный префикс).
