# Web: SSTI через формат сейва (Pokebox — Pokémon Gen III save)

Суть: пользовательский сейв-файл игры (Game Boy Advance — Pokémon) вставляется
в шаблон без санитизации → Server-Side Template Injection.

## Шаги
1. Определить формат .sav (Gen III: размер 128КБ; структура блоков; таблица
   символов и ники персонажей хранятся в data-зонах).
2. Восстановить таблицу символов (обычно «little-endian» строки; кодировка
   игры — 8-битная с собственным набором).
3. Если сервер рендерит имя тренера/Покемона прямо в шаблон — подставить
   SSTI-выражение вида `{{7*7}}` или `{{ ''.__class__.__mro__[1].__subclasses__() }}`.
4. Прочитать флаг через RCE-цепочку (например, `__subclasses__` → module →
   read file).

## Итог
- Любой пользовательский контент, попадающий в шаблон (имя, ники) → попробовать SSTI.
- Проверять сразу классические `{{7*7}}`, затем глубокую цепочку.
