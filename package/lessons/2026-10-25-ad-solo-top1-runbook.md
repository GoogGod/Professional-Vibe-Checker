# Урок: ранбук соло-топ-1 для Attack/Defense
Дата: 2026-10-25 · Категории: attack/defense, process, strategy · Детали: `local/tactics/ad-field-notes.md`, `toolbox/ad/README.md`

## Формула топ-1
SLA 4×100% + ноль дренажа + 3–4 живые линии + скорость первого часа (round-sync). Победитель — не лучший взломщик, а самый стабильный.

## План соло
- **T-1**: репетиция на mock_jury (см. `toolbox/ad/README.md`) + preflight.
- **Первый час (сеть закрыта)**: подключение ≤10 мин, список сервисов из API, checker-first по каждому (ниже), бэкап, размеченный first blood, farm/watch подняты.
- **Открытие атаки**: farm непрерывно, первый эксплойт без полировки, анти-дренаж watch слушает `/public/attacks`, сводки каждые 10 мин одним абзацем.
- **Третий час**: закрыть свои дыры (по данным дренажа), патч = чекер-тест → снапшот.
- **Обед (сеть закрыта)**: глубокий RE сложного сервиса субагентом, рискованные патчи, заготовка эксплойтов.
- **Послеобед**: майнинг `/public/attacks` (чужие векторы), tcpdump+реплей атак.
- **Предфинал**: экономика линий, добивка SLA до 100%.
- **Последний час**: заморозка — никаких изменений, только кража и сабмит.

## Checker-first (главный навык)
Чекер = карта хранения флагов. Логи `/public/scoreboard/teamtasks/<team>/<task>/logs`. Для каждого сервиса письменно: «кладёт через X, хранит в Y, hint=Z». Это половина эксплойта + spec патча + чекер-тест.

## Патч-таксономия
- **L0 откат** — мгновенно при не-OK (дыра открыта, но статус важен).
- **L1 канализация** — дефолт для соло: рандомизировать/зашифровать хранилище флага. Блокирует эксплойт, чекер доволен.
- **L2 точечное закрытие** — валидация ровно в месте вектора + чекер-тест.
- **L3 ре-архитект** — никогда в игре.
- NAT → никаких IP-банов.

## Анти-дренаж
Зелёный ≠ не доят. watch.py v2 считает flag_stolen против нас из `/public/attacks`, порог 3+/раунд → DRAIN-алерт → L1-канализация. «already stolen»>50% → линию в пенсион.

## Экономика линий
Метрики: попытки/флаги/already stolen%/длительность. 25+ попыток и 0 флагов → RETIRE. Round-sync через `/api/v1/ctftime`: кража в первые секунды. Новый эксплойт от субагента = файл в exploits/ + рестарт фермы. Соло = 2–3 простых линии, не один красивый реверс.

## Командирский цикл
Главный чат = mission control (решения и сводки); тяжёлое — субагентам (spawn_task по сервису); STATE.md на диске — источник правды; эскалация оператору — только решения; демоны `setsid nohup` переживают всё.

## Архетипы (15 мин на классификацию)
- CRUD-хранилище → закрыть проекцию + канализировать хранение флага.
- JWT/сессии → проверить алгоритм/секрет + серверная проверка владельца.
- Парсер → гвард-клаусы на ввод (паники = MUMBLE).
- Гонка/TOCTOU → если чекер всегда первый — в пропуск.

## Проверенный мок
mock_jury: ферма крадёт и сдаёт («Flag accepted!»), watch видит статусы, /admin/patch → CORRUPT-алерт, /admin/rollback → OK, отключение эксплойта не роняет ферму.
