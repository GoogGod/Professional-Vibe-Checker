# 2026-11-01 — Потоковые шифры: many-time pad и повтор nonce (CTR)

Источник опыта: серия платформа-задач «Сумма вместо отпечатка» серии; приёмы полностью переносимы.

## 1. Many-time pad (повтор гаммы)
- Если один и тот же keystream использован для нескольких сообщений (ct[0], ct[1], …),
  а одно сообщение (plaintext) известно: `gamma = plaintext XOR ct[0]`.
- Любой другой шифртекст расшифровывается: `plaintext_i = ct[i] XOR gamma`.
- Признак: одинаковые длины сообщений, общий фрагмент/формат (например, флаг), повторный nonce/key.
- Флаг (пример): `[FLAG]`.

## 2. CTR с повторным nonce
- Если nonce повторяется между шифрованиями — keystream одинаковый → та же атака, что many-time pad.
- Восстановление keystream по известной паре: `ks = known_plain XOR ct_known` → расшифровка цели.
- Флаг (пример): `[FLAG]`.

## 3. Генераторы с известной начинкой (биты)
- Если «генератор» выдаёт байты/биты по 1 кандидату на бит (например, 128 кандидатов → 128 бит),
  собери их в байты: `bits` → `bytes` (8 бит на байт) → ASCII.
- Пример: 128 кандидатов → 16 байт ASCII `units_form_group`.
- Ключевой приём: **посчитай, сколько бит/байт нужно на флаг** — это подсказывает количество кандидатов.

## 4. Веб/сеть — никаких кавычек в командах
- В PowerShell нельзя `python - <<'PY'` (heredoc не поддерживается). Всегда пиши скрипт через Write
  и запускай `python file.py` (или py_run).
- net_session требует `host` — всегда передавай `{"host": "...", "port": N}`.

## Связанные рецепты в скилле
- LFSR с известным префиксом → Berlekamp–Massey (crypto-solver-archive).
- ECB-структуры и коллизии — см. урок `block-cipher-structures-ecb-oracle-digest-collision`.
