# Урок: CTF-pcap — LSB в первом столбце + кастомный base64-алфавит

**Дата:** 2026-10-23 · **Категория:** forensics/stego · **Сложность:** easy

## Условие
Перехвачен трафик (task.pcap.txt — на деле бинарный pcap v2.4). Найти скрытую информацию.

## Решение (цепочка)
1. `tshark -z conv,tcp/udp`: 192.168.56.128 (жертва, Kasper) ←→ 192.168.56.1 (атакующий).
   Порт **11222** — reverse-PowerShell (follow stream: баннер PS, ввод команд атакующим).
2. По C2: `Invoke-WebRequest /funny_cat.png` (736×661 RGBA), запуск `encoder.exe`, вывод:
   `key: UVeYSKmgtIaGru41NBsCblcHMqjikynLh9px5` (37 симв.), безымянная строка
   `FXv0ROTdJWDzEw3Q7o6fP2AZ8+/=` (28), `bits: 928`, `used bit: one`.
3. `--export-objects http`: funny_cat.png (RGBA, альфа вся 255) и very_funny_cat.png (RGB).
   Сравнение пикселей: **отличие ровно LSB-ами 258 пикселей, все в столбце x=0, строки 1..309**.
4. LSB col0 (R,G,B interleave, MSB-first) very_funny → base64-строка ровно **116 симв = 928 бит**
   (совпало с `bits: 928`): `eXBF...==`. Обычный base64-decode → 85 байт бинарного мусора.
5. Ключ к разгадке: **37 + 27 = 64**. Безымянная строка без `=` — ровно 27 символов,
   не пересекающихся с key; вместе покрывают весь стандартный base64-алфавит →
   это **кастомный (переставленный) base64-алфавит**: alphabet = key + FXv0...(без =).
6. Декод строки из LSB кастомным алфавитом → Python-код:
   `def secret_message(): print("[FLAG]")` — флаг.
   Тема «The Other Side» = ASCII-арт с двумя человечками и стрелками ↔ в выводе encoder.exe.

## Сэкономленное время
- battery AES/RC4/ChaCha/XOR по 85-байтному raw — тупик (это был валидный base64 с ЧУЖИМ алфавитом).
- Гадать шифр по hex-мусору после base64-decode — сначала проверить, не кастомный ли алфавит.

## Признаки-маркеры на будущее
- Вывод утилиты: `key: <37 симв>` + строка base64-подобная на 27-28 симв → 37+27=64 = кастомный base64.
- «bits: N» помогает проверить длину извлечённого payload (928 бит = 116 симв ASCII).
- Стего-диф картинок: `np.abs(a-b).max()==1` → менялся только LSB; `np.nonzero(diff)` даёт карту
  (здесь — один столбец x=0, порядок чтения R,G,B по строкам, MSB-first).
- Формат ответа может быть «просто строка», не только флаг-регекс (указание оператора).
