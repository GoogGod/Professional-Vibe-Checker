# CBC padding oracle против стороннего веб-сервиса (devglan)

Контекст: на Reddit (r/codes) опубликовали строку `sCmxMdZ/vRqjAToDmLMw+sv55IkG5/CeDf0DaW27DU5s49ZtyninNpmDlMtskoru`
из названия YouTube-видео; решение — онлайн-шифратор/дешифратор devglan (AES-CBC, ключ «lain»/пустой). Вопрос: как это сделать локально, без сайта? Ответ: атака padding oracle на публичный оракул devglan.

## Механика
- Сервис `https://www.devglan.com/online-tools/text-encryption-decryption` расшифровывает присланный base64-шифротекст с указанным ключом и отвечает `{"decryptedText": ...}` при валидном PKCS7-padding, либо ошибкой.
- Это классический CBC padding oracle: изменяя байты предыдущего блока (IV/C[i-1]) и наблюдая «валиден ли padding», восстанавливаем промежуточные состояния `I[i]=Dec(C[i])` побайтно (16 позиций × до 256 кандидатов), затем `P[i]=I[i] XOR C[i-1]`.
- Для первого блока вместо C[-1] нужен IV. IV восстановлен по контрольной паре: `encrypt("0000000000000000") → OwjEkLLE0wJnLLhooqlqIGMs9HroujNW2UtpmNfiprg=` (ссылка на devglan с этим текстом даёт этот шифротекст). `IV = I_ref0 XOR "0000000000000000"`.
- Итог: `"and you don't seem to understand"` (padding 16 байтов PKCS7 отрезан).

## Практические грабли
- Сервер выдаёт «Page expired» — нужен refresh токена из `<meta name="dg-token">` и куки сессии (requests.Session с keep-alive).
- Rate-limit: больше 2 параллельных запросов на сессию → падение части ответов (перебор с 3-4 Workers теряет кандидатов). Рабочий режим: 2 потока.
- retry делать только при СЕТЕВЫХ сбоях/Page expired; стабильный «False» от расшифровки ретраить нельзя (иначе время позиции раздувается ×5).
- Токены/сессии «умирают» при долгих прогонах → при пустом списке кандидатов пересоздавать сессии и повторять перебор (до 3 раундов).
- Фоновые Bash-задачи не переживают завершение сессии платформы — запуск через `Start-Process` (убитый PID остаётся жить) либо чекпойнт на диск (oracle_state6.json: IV/I0/I1/I2), чтобы продолжать после рестарта.
- 16-байтовые блоки из base64-строки: 48 символов → 48 байт → 3 блока; жёсткий фиксированный PKCS7-padding (0x10×16) у «ровной» длины.
