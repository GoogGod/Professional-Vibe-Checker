# Lesson: iso (2-изогении, j-инвариант от флага)

## Урок 1. cubic_roots: классический баг частичного расщепления
- Ошибка: при частичном split (линейный фактор h2) возвращались только его корни, остальные терялись.
- Симптом: синтетика проходит случайно (tree может содержать лист-двойник), но не стабильно.
- Фикс: только полная факторизация (sqfree → gcd(x^p−x) → CZ split рекурсивно) + верификация корней прямой подстановкой.

## Урок 2. CPython random.seed(int) / getrandbits для эмуляции Sage
- random.seed(int) → init_by_array на 32-битных LE-словах abs(int).
- getrandbits(k) → первое сгенерированное слово — МЛАДШЕЕ (LE bytearray), не старшее!
- Sage: python_random() пересеивается от ZZ.random_element(1<<128) при первом обращении.

## Урок 3. C-аналог poly-арифметики
- poly_mul(r,u,v) с r==u или r==v: обязательно копировать входы, иначе мусор.
- mpz_invert(NULL) — segfault (заглушки забыть).
- Дедуп уровней дерева обязателен: без set() дерево экспоненциально взрывается дубликатами.

## Урок 4. Оптимизация скорости
- Дерево изогений живёт у ~50% p → фильтр слабый; свип сидов медленный (~2.3с/сид C).
- Вероятность корня кубики над F_p ~70% → деревья почти не умирают на первых уровнях, взрывается рост.

## Урок 5. WSL/PowerShell
