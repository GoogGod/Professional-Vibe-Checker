# Миск: connectome — большой граф и «ключ в мозгу мухи»

Суть: дан CSV с рёбрами коннектома (src_id,dst_id) ~9М рёбер; где-то в структуре
спрятан флаг. Типичная «графовая» форензика: извлечь подграф/метрику,
содержащую ключевую последовательность.

## Первичный анализ
- Файл csv.gz (8.9М строк): рёбра без весов.
- Числа id — не последовательные; есть миллионы вершин; степень распределена
  по степенному закону (неравномерно).

## Что искать
- Необычные строки: id за пределами диапазона, рёбра с самопетлями,
  повторяющиеся пары (мультиграф).
- Выделить подграф «особых» вершин (например, id = одним числом, совпадающие
  с ASCII/hex флага или «fly brain» узлов).
- Построить распределение степеней; искать вершины с уникальной степенью
  (1, 2, 3...), которые кодируют байты флага.
- Проверить: может ли флаг быть последовательностью id (в десятичном или
  hex виде) или ASCII-кодом уникальных степеней.

## Бонус-подсказка
- Если данных слишком много — парсить на лету (pandas chunked), не грузить
  целиком.

## Итог
- Графовые «ключи» ищутся через уникальные метрики (степень, центральность),
  аномалии и связные компоненты; не читать весь граф глазами.
