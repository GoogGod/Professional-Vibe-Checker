# LFSR-шифр: восстановление рекуррентности по известному префиксу (Berlekamp–Massey)

Суть: потоковый шифр на LFSR — keystream генерируется регистром сдвига
(seed известен, обратная связь/taps — нет), текст шифруется XOR'ом с
keystream. Известен префикс открытого текста (например, начало флага).

## Алгоритм
1. XOR префикса plaintext с соответствующей частью ciphertext → первые L
   бит keystream (L — длина регистра, напр. 64 бита).
2. По первым 2L битам keystream построить минимальную рекуррентность
   (полином обратной связи) через **Berlekamp–Massey** → степень L.
3. Продолжить keystream по рекуррентности (сдвиг + XOR отобранных бит).
4. Расшифровать весь ciphertext: `pt = ct XOR ks`.

## Грабли
- Keystream считается **по битам** (не байтам) — сначала собрать все биты,
  потом упаковать в байты.
- Известный префикс — это обычно начало флага; если флаг начинается с
  известной сигнатуры, достаточно 64–128 бит префикса.
- Проверить гипотезу о длине регистра: BMA выдаёт L; убедиться, что
  продолженный keystream даёт осмысленный остаток текста.
- Если регистр байтовый — алгоритм аналогичен, но над GF(2^8): решать
  линейную систему по байтам-состояниям.

## Пример успеха (2026-10-30)
Платформа, средняя сложность: xor-шифр, seed известен, taps неизвестны.
Префикс флага → keystream (64 бита) → BMA дал L=31 → keystream продолжен →
расшифровка. Флаг принят платформой.
