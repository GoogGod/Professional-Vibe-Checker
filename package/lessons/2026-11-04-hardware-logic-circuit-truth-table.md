# Логическая схема: восстановление булевой логики по таблице истинности

Суть: задача «Логика» (hardware/easy). Входы x1..x8, выход X9 в
таблице из сотен строк; схема дана рисунком/слоями (PDF, XLSX).

## Алгоритм
1. Распаковать вложения (zip/xlsx), извлечь таблицу входов:
   `x1..x8` для каждой строки, `X9` пуст (надо вычислить).
2. Восстановить схему по рисунку/описанию: разложить на простые
   элементы: NOT, AND, OR, XOR, XNOR. Переписать в виде выражений:
   - `x1_2 = NOT(x1)`
   - `x23 = x2 XOR x3`
   - `x123 = x23 AND x1_2`
   - `x45 = x4 AND x5`; `x45_2 = NOT(x45)`
   - `x12345 = x45_2 OR x123`
   - `x67 = NOT(x6 OR x7_2)` ≡ `NOT(x6) AND x7`
   - `x78 = NOT(x7 XOR x8)` (XNOR)
   - `x678 = x78 OR x67`
   - `X9 = x12345 OR x678`
3. Вычислить X9 для всех строк (скрипт) → битовый вектор
   (порядок строк, MSB-first) → декодировать в ASCII → флаг.

## Грабли
- Проверить порядок битов: MSB-first по строкам (флаг читается).
- Если выходов >1 — биты складывать по порядку.
- Лишние входы (например, 112 пропущенных векторов из 256) допустимы:
  достаточно имеющихся строк; пустые/пропущенные строки не ломают вектор.
- Ситуации «флаг как результат вычисления» — распространены в
  «логических» задачах: таблица истинности специально подобрана так,
  что выходной битовый вектор даёт флаг.

## Проверка
`X9=1` в ~половине строк; уникальных входных векторов меньше общего
числа строк — нормально.
