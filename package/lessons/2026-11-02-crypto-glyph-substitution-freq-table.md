# Визуальный шифр на глифах: биграммы + таблица частот

Суть: шифротекст — сетка растровых символов (эмодзи/пиктограммы/Form XObject);
рядом — легенда из нескольких пар «глиф → символы» и таблица частот символов текста.
Флаг часто вида `hash(слово)`.

## Модель
1. Единица шифрования — **биграмма** (пара букв): один глиф = одна биграмма.
2. Моноалфавитная подстановка: глиф → одна и та же биграмма во всём тексте.
3. Пробелы выброшены; текст — сплошная строка без пробелов.
4. Легенда даёт ~12 пар (зацепка), остальные сотни глифов восстанавливаются по частотам.

## Алгоритм
1. Извлечь глифы: растеризовать Form XObject/Type3, кластеризовать попиксельно
   (NCC/гистограмма/хэш миниатюры). Число классов = размер алфавита шифра.
2. Подсчитать частоты уникальных глифов в сетке.
3. Сопоставить с таблицей частот биграмм (частые глифы = частые биграммы).
4. Наложить известные пары из легенды.
5. Развернуть текст; применить языковую модель (словарь форм слова) для проверки
   осмысленности и подбора оптимального маппинга.
6. Прочитать ВЕСЬ текст (тысячи знаков), не останавливаясь на первых строках.

## Целевое слово (если флаг = hash(слово))
- Ищи слово, которое семантически «выпадает» из ряда (редкое, неочевидное),
  а НЕ заголовок/самое частое слово.
- Собери 5–10 кандидатов из полного текста, посчитай hash всех, проверяй по очереди.

## Грабли
- Не OCR-читать глифы как буквы/QR — это растровые формы (пиксельная кластеризация).
- Заголовок/метаданные ≠ слово-ответ (это тема).
- Таблица частот рядом с легендой — ЧАСТЬ КЛЮЧА, не игнорировать.
- Без восстановления всех ~480 биграмм текст не прочитается.

Пример успеха (2026-11-01): 12 пар легенды → фраза из 5 слов; 492 класса глифов;
редкое слово-ответ из полного текста; флаг принят платформой.
