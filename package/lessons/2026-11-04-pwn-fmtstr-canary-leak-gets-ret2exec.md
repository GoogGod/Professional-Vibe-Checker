# PWN: утечка canary через формат-строку и переполнение gets → готовый вызов system(cmd)

Суть: меню с `printf(name)` (формат-строка) и последующим `gets(dest)`
(переполнение). Не обязателен полный ROP: в бинарнике уже есть блок
`lea rax,[cmd]; mov rdi,rax; call system@plt`.

## Алгоритм
1. Утечка canary: ввести `%15$p` (номер позиции подобрать: 10–20) в
   качестве name → ответ `0x…` — canary.
2. Собрать payload: `'A'*(offset) + canary + 'B'*8 + return_addr`, где
   offset = размер буфера до canary (обычно `rbp-N` → `N+8`).
3. return_addr = адрес фрагмента `lea rax,[cmd]; mov rdi,rax; call system@plt`
   (искать в дизассемблере по строке команды).
4. Отправить payload в `gets` → `system(cmd)`.

## Грабли
- `printf(name)` выводит только до первого пробела: для утечки `%15$p`
  без пробелов.
- После `gets` вывод может гаситься при несовпадении canary — проверить
  canary утечки (низший байт = 0x00).
- Поиск позиции аргумента: `%1$p..%30$p` — canary обычно 15-й (x86-64).
