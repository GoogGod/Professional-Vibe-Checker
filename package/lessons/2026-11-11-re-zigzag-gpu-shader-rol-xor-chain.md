# RE hard: zigzag.exe — GPU шейдерная проверка флага (GLFW/OpenGL)

Дата: 2026-11-11. Категория: reverse (hard). Платформа: обобщённо.

## Суть
PE32+ x64, статически слинкованный C++ (GLFW + OpenGL 4.3 core), без таблицы импортов (но есть загрузчик gl-функций). Программа читает флаг из stdin (по 1 байту через ReadFile), требует длину кратную 4 и >= 8; разбивает на DWORD.

Проверка: для каждой пары соседних DWORD (input[i], input[i+1]) грузит uniform `skibidi` = 4 байта DWORD i, `sigma` = 4 байта DWORD i+1 (по 1 байту на компоненту uvec4), рисует полноэкранные 2 треугольника на FBO 64×64, читает из SSBO один uvec4 (выбирается строкой пикселей по индексу `byte_14004B602[i]`, 16 байт) и сравнивает с эталоном.

## Ключевые приёмы
- Recon: строки `Enter flag: ` / `God damn...` / `Nah, mate...` + импорты-строки `glShaderSource`, `glCompileShader` и т.п. указывают на GL-проверку; код шейдеров лежит в .rdata как **zlib**-сжатые блоки (`78 9c`) с длинами 115/432 байта — распаковать `zlib.decompress`.
- Расшифровка фрагментного шейдера (GLSL 430):
  - `skrrr(x,s)=((x<<s)|(x>>(8-s)))&0xFF` = ROL8; `bruh(x,s)` = ROR8 (компоненты uvec4 <= 255).
  - формула на пиксель x: out0 = ROR5(skibidi.x) ^ ROL3(sigma.x) ^ (x*0x9E3779B9); out1 = ROL7(skibidi.y) ^ ROL1(sigma.y) ^ (x*0x7F4A7C15); out2 = ROR4(skibidi.z ^ sigma.z) ^ (x*0x6A09E667); out3 = ROL6(skibidi.w ^ sigma.w) ^ (x*0xBB67AE85).
- Эталон: 10 блоков по 16 байт = 144 байта из `unk_14004B618` + 16 байт из `xmmword_1400555C0` (отдельная переменная, но код сравнивает 10-й блок с ней — буфер переполняется из v50 в v51).
- Индексы пикселей: `byte_14004B602[0..9]` = [0x1d,0x2c,0x28,0x09,0x2e,0x30,0x2d,0x26,0x3b,0x01].
- Решение: первый DWORD = "DUCK" (формат DUCKERZ{...}), далее цепочка рекуррентных формул (обратные к ROL/ROR + XOR):
  g0 = ROR3(K0 ^ ROR5(s0)), g1 = ROR1(K1 ^ ROL7(s1)), g2 = s2 ^ ROL4(K2), g3 = s3 ^ ROR6(K3), где K = (T[i] ^ (x*const)) & 0xFF.
- Forward-проверка сошлась с эталоном (все 10 блоков) — флаг [FLAG]. Запуск не использовался (нужен GPU/окно).

## Вывод
Флаг → [FLAG]. Формат DUCKERZ{...} (44 символа, 11 DWORD).

## Анти-деанон
Без названий площадок, доменов, имён. Флаг → [FLAG].
