# RSA: параметры в восьмеричной системе, известная разность p−q

- Дата: 2026-10-29, задача OCTOSQUARE (платформа, крипто, средняя).
- Условие: N, e, p−q, C в base-8. `e = 200001₈ = 65537` (классика). Длина N ~1023 бит.
- Приём: по Φ(N) = (p−1)(q−1) и p−q:
  - `(p+q)² = 4N + (p−q)²` → `p+q = isqrt(4N + diff²)` (проверить точность квадрата);
  - `p = ((p+q) + (p−q))/2`, `q = ((p+q) − (p−q))/2`; обязательная проверка `p*q == N`;
  - `d = pow(e, -1, phi)` → `m = pow(C, d, N)` → байты.
- Результат: `m = b'Qw1r'` → флаг `[FLAG]` (значение конкретной задачи).
- Важно: все числа парсить `int(x, 8)`; знак diff — попробовать оба (+/−); проверка `p*q==N` отсекает неверный знак.
- Солвер: `toolbox/solve_rsa_oct_diff.py` (в архиве: solve_octosquare.py).
