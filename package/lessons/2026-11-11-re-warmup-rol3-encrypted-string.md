# RE easy: warmup — ROL3 + сравнение со строкой

Дата: 2026-11-11. Категория: reverse (easy). Платформа: обобщённо (не упоминается).

## Суть
ELF64 x86-64, динамический, ~16 КБ. Программа:
1. `fgets` ввода в буфер (до 256), срезает `\n` через `strcspn`;
2. копирует в `dest` (`strcpy`);
3. вызывает `transform_string(dest)` — цикл по байтам до NUL, каждый байт:
   `b = (b >> 5) | (8 * b)` — это **ROL3** (rotate left 3) для unsigned 8-битных;
4. `strcmp(dest, encrypted)` → "Верно"/"Неверно" (UTF-8 строки в .rodata).

## Ключевые приёмы
- IDA headless recon: импорты `strcmp/fgets/strcpy` + функция `transform_string` + строка-кандидат сразу указывают на «трансформируй ввод и сравни».
- Строка `encrypted` (метка IDA) — не ASCII, лежит в .rodata; читать байты до NUL (у нас 30 байт @ 0x2010) через `idc.get_bytes`.
- **Ловушка инверсии**: `((b<<3)|(b>>5))&0xff` — это ТО ЖЕ, что transform (не инверсия!). Инверсия ROL3 = **ROR3**: `((b>>3)|(b<<5))&0xff`.
- Контроль: `bytes(fwd(b) for b in flag) == encrypted` → True; запуск `printf 'FLAG\n' | ./warmup` → «Верно» (запуск через WSL, каталог /mnt/c/...).

## Вывод
Флаг → [FLAG]. Формат DUCKERZ{...}.

## Анти-деанон
Без названий площадок, доменов, имён. Флаг → [FLAG].
