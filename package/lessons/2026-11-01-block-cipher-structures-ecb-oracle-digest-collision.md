# 2026-11-01 — Структуры блочных шифров: ECB-оракул, коллизия суммы байтов

Источник: платформа «Криптография. Симметричные примитивы» (ECB, digest-сумма).

## 1. ECB — словарь блоков (побайтный оракул)
- ECB расшифровывает одинаковые блоки одинаково → можно строить словарь из 16-байтовых блоков.
- Побайтный оракул: подбирай байт так, чтобы образовался желаемый блок, сравнивай с эталонным.
- Восстановление произвольного блока при условиях:
  - есть контроль над вводом (куда записывается неизвестная часть) и
  - число повторений блока на одном месте ограничено 2–3 (иначе появится «полка»).
- Сигнатура быстрых задач: «ECB — детерминированный, блоки не скреплены».
- Флаг (пример): `[FLAG]`.

## 2. Самодельный «отпечаток» — сумма байтов по модулю N
- hash = сумма байтов (по `mod 65521` и т.п.) — коллизия тривиальна: меняй байты с равным
  «весом», следи за префиксом/шаблоном, считай сумму фиксированной части.
- Пример: `hash_swap_` (без суффикса) = 1053; две цифры дают `1053 + (48+a) + (48+b) = 1149+a+b`;
  нужно `1149+a+b ≡ 1155` → `a+b = 6` → кандидаты 06, 15, 24, **33**, 42, 51.
- Общее правило: **определи сумму фиксированной части**, затем подбери переменную часть под нужный остаток.

## 3. Подводные камни
- Не сразу писать громоздкий солвер — сначала посчитай модульную арифметику на бумаге (это экономит минуты).
- В PowerShell: отсутствие heredoc — всегда `python f.py`.
- Проверяй наличие файла перед Read, иначе «Cannot find file».
