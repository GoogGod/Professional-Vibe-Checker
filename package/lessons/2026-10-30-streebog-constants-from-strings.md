# 2026-10-30 — Стрибог: итерационные константы из строк (CP1251 → hex UPPER → разворот байтов хэша)

Суть: в реализации ГОСТ Р 34.11-2012 (Стрибог-512) итерационные константы
не заполнены; часть констант (например, две последние) дана как контроль.
Константы получены хэшированием строк-шаблонов на естественном языке.

## Метод генерации константы
Для строки `s` вида `константа_<NN>_<MM>_<YYYY>_<день недели>`:
1. `b = s.encode('cp1251')`
2. `hx = b.hex().upper()` — hex-запись, ВЕРХНИЙ регистр
3. `data = hx.encode('ascii')` — hex как ASCII-текст
4. `h = streebog512(data)` — эталонная реализация, стандартные константы RFC 6986
5. Константа = `h[::-1].hex()` — разворот БАЙТОВ результата (не hex-строки!)

## Проверка метода
Если даны контрольные пары (строка → константа): сгенерировать по методу
и сверить 1-в-1. Подтверждено на двух парах (строка «константа_11_08_2026_вторник»
→ `ad444c…5240e`; «константа_12_08_2026_среда» → `25d22a…2737e6`).

## Выпавшая позиция
В последовательности шаблонов одна позиция может НЕ следовать календарю:
число повторяется (дважды), а день недели не совпадает с реальным календарём.
Точное значение добирается перебором по первому контрольному вектору.

## Ложные варианты (проверены, НЕ совпадают)
- без разворота байтов; без upper; разворот hex-строки как текста;
- стрибог-256; Hinit (нулевые константы); прямое хэширование байтов строки;
- UTF-8/UTF-16 вместо CP1251; транслит; английские дни недели.
