# 2026-10-30 — стрибог-константы из строк (CP1251 → hex UPPER → разворот байтов хэша)

Задача «Повелитель ветров» (DEVCTF): в реализации ГОСТ Р 34.11-2012 (Стрибог-512)
не заполнены 10 итерационных констант; C11/C12 даны как контроль.

## Метод генерации константы (из подсказки)
Для строки `s` (например `константа_11_08_2026_вторник`):
1. `b = s.encode('cp1251')`
2. `hx = b.hex().upper()` — hex-запись, ВЕРХНИЙ регистр
3. `data = hx.encode('ascii')` — hex как ASCII-текст
4. `h = streebog512(data)` — эталонная реализация, стандартные константы RFC 6986
5. Константа = `h[::-1].hex()` — разворот БАЙТОВ результата (не hex-строки!)

## Проверка метода
- `make_const('константа_11_08_2026_вторник')` == авторская C11 (`ad444c…5240e`) ✓
- `make_const('константа_12_08_2026_среда')` == авторская C12 (`25d22a…2737e6`) ✓

## Выпавшая позиция
C10 ≠ «константа_10_08_2026_…». Перебор по первому контрольному примеру
(M1 = 63 байта, ожидание `9aa1c1a4…3674101`):
- C10 = «константа_11_08_2026_понедельник» (число 11, день — понедельник,
  НЕ совпадает с календарём: 11.08.2026 — вторник; число 10 отсутствует).

## Результат
- Тест 1 (M1): `9aa1c1a40aed402c…f3674101` — True (константы верны).
- Тест 2 (M2): хэш = флаг (значение конкретной задачи; НЕ публикуется).
