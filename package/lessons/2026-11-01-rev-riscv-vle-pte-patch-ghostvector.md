# Reversing: RISC-V vector instruction (VLE) как «window» в память

Суть: эмулятор/виртуальная машина исполняет RISC-V; отдельная инструкция
векторного расширения (VLE) оказалась способной писать в произвольную память.

## Предпосылки
- Виртуальная машина с памятью (load/store) и страницами физической памяти.
- Флаг лежит на странице, которую процесс не может прочитать напрямую (недоступна,
  защищена PTE-битами).

## Приёмы
1. Декодировать `.word`-константу: `0x00b5700b` → VLE (Vector Load Element):
   векторный регистр, VL=1, SEW=8, смещение — байты пишутся по П-ИЗ-адресу.
2. Патчить PTE (page table entry) у страницы с флагом побайтно
   (установить readable) → затем mprotect/страница становится читаемой.
3. Читать флаг по физическому адресу из эмулятора.

## Итог
- Проверять векторные инструкции: они часто не проходят обычные проверки
  (bounds/не влезают в классический метрикк).
- PTE-патч побайтно — рабочий способ «открыть» страницу.
