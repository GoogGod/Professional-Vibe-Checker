# 2026-11-15 — CFF-сетевая REV: кастомный фрейм-протокол и подмена результатов вызовов

Задача: бинарник-клиент (Rust x64 PE32+) исполняет серверные образы машинного кода (BlockImage), присланные сервером; сервер валидирует каждый результат вызова. Победа = корректный ввод в stdin.

## Суть протокола
- Кадр: `[u32 len][payload]`, payload = `[u32 variant][поля]`.
- Клиентское hello: `04 00 00 00 | 00 00 00 00` (len=4, variant=0).
- Сервер шлёт образ кода (вместе со строками UI: "input: ", "wrong\n", "accepted") — клиент исполняет его локально.
- Каждый изолированный вызов клиент передаёт серверу кадром `Call { id, result }`: `[u32 len=0x14][u32 var=1][u64 id][u64 result]`.
- Ответы сервера: variant 0 = BlockImage, 1 = Call (2 поля), 2 = PopFrame, 3 = Finish (успех), 4 = Error.
- При неподходящем результате сервер шлёт Error, и клиент печатает "input: wrong" (строка из первого серверного блока).

## Ключевые приёмы
1. **Прокси-подмена результата вызова** (MITM-прокси между клиентом и сервером):
   - В C2S-кадре подменяем `result` (смещение 12..20 от начала payload) на нужную константу.
   - Трейс кадров S2C/C2S по строкам с парсингом `[u32 len][payload]`.
   - Подмена результата критичного узла на подходящую константу предотвращает Error и позволяет диалогу продолжаться.
2. **Поиск критичного узла**: разбор блоков (дизассемблирование кода образов), поиск сравнений `cmp [reg+off], 0` — это и есть развилки валидации.
3. **Интерактивная сессия**: прокси + ввод 'm' показал, что сервер сам вызывает узел 0x059bd с результатом 0x27fc84cc57de41bd (константа из тела узла).
4. **Фильтры по stdin**: строка читается с '\n', сервер ждёт ровно один байт/слово.

## Урок
- Для сетевых VM-челленджей: сначала восстановить протокол кадров, затем подменой результата в прокси определить критичные развилки, а не брутфорсить всё вслепую.
- Если перебор констант не даёт успеха — строить локальный эмулятор VM-интерпретатора.
- "wrong" печатается серверным кодом, а не клиентом: диагностика через трейс кадров, а не через stdout.

## Анти-паттерн
- Не подменять результат узла на произвольную константу без её проверки: сервер валидирует и продолжает диалог только при совпадении с зашитой в код константой.
