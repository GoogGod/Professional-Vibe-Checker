# OSINT Workbench — факты вместо угадывания

Модель не «узнаёт место по фото» — она строит правдоподобные догадки. Рабочий цикл другой: **собери наблюдаемые факты из артефакта → преврати каждый факт в ограничение → проверь ограничения поиском → потребуй 5+ независимых подтверждений**. Ответ без таблицы подтверждений — не ответ.

## 1. Артефакт-паспорт — прежде любого поиска

```sh
file artifact.*
exiftool -a -u -g1 artifact.*        # ВСЁ: GPS, timestamps, камера/серийник, софт, комментарий
strings -n 8 artifact.* | head -50
binwalk -e artifact.*                # вложения
```

- **GPS**: `exiftool -n` (числовые координаты) → сразу на карту (web_search / OSM). GPS в CTF часто сдвинут или это отправная точка, а не ответ.
- **Скриншоты**: язык интерфейса, формат даты/времени, иконки погоды/батареи, часовой пояс системных часов, ник/аватар в углу, URL в адресной строке, артефакты окна (скроллбар, раскладка).
- **Документы (PDF/DOCX)**: автор, компания, принтер, путь-шаблон в метаданных (часто содержит логин владельца), версии ПО. `exiftool`, `mutool show file.pdf`, для OOXML — `unzip -p doc.docx docProps/core.xml`.
- Всё внеси в таблицу FACTS: `факт | источник | ограничение, которое он создаёт`.

## 2. Геолокация по фото — чек-лист признаков

Пройди ВСЕ пункты, каждый записывает ограничение (страна/регион/полушарие):

| Признак | Что даёт |
|---|---|
| Сторона движения | лево/право-движение → короткий список стран |
| Формат автономеров | длина, цвет фона, кириллица/латиница, EU-полоса |
| Дорожные знаки | форма (Вена vs MUTCD vs местная), язык, единицы (км/мили) |
| Электросетка | форма столбов, провода (EU vs US vs JP), напряжение табличек |
| Вывески/язык | алфавит, диакритика, типографика брендов |
| Растительность/климат | пальмы/хвойные/лиственные → широтная полоса, сезон |
| Архитектура | материал кровли, окна, кондиционеры, заборы |
| Солнце/тени | направление и длина → полушарие + широтный диапазон + сезон |
| Люди | одежда (сезон/культура), форма (служба) |
| Артефакты | розетки, мусорные баки, люки (маркировка), почтовые ящики |

**Тени → координаты (числа, не вайб):** высота объекта H и длина тени L → `tan(alt) = H/L`; направление тени + местное время из EXIF/условия → азимут солнца. Сравни с калькулятором (suncalc-style через web_search «sun position calculator» или python `astral`). Это сужает широту до пояса и верифицирует часовой пояс.

**Сверка с картой:** 3+ уникальных ориентира (форма здания, водонапорка, мост, антenna, разметка парковки) → карты/спутник через web_search / browser (OSM, спутниковые слои). Панорамы разных лет: старые кадры раскрывают изменившееся.

## 3. Люди и ники

- Перебор площадок по нику (статусы HTTP): однострочник curl по списку популярных сайтов (напиши по условию задачи; для CTF обычно 5–15 площадок из описания).
- `web_search "точный ник"` в кавычках + вариации (разделители, леetspeak).
- Валидация совпадения: даты регистрации, аватар (один файл → один хэш), стиль писем, лайки/подписки. Одно совпадение ника ≠ тот же человек — требуй 2+ косвенных.
- Соцсети в browser MCP/playwright, если нужна интерактивность (скролл, комментарии).
- Этика: только персонажи задачи/публичные данные учебных целей; никаких действий против реальных людей (письма, добавления, деанон ради деанона).

## 4. Инфраструктурный OSINT (домены/IP/сервисы)

```sh
whois example.com
dig ANY example.com +short        # и исторические: web_search "example.com" ip-history
```
- Сертификаты: `https://crt.sh/?q=%.example.com` (поддомены).
- Архивы: `https://web.archive.org/web/2023*/example.com` — старые версии страниц, удалённые контакты.
- Операторы поиска: `site:`, `filetype:pdf`, `inurl:`, `intitle:`, `"точная фраза"`, `-исключить`.
- Код: github search / grep.app по строкам из артефакта (строки ошибки, комментарии).
- Публичные сканеры (Shodan/Censys/FOFA) — только при явном ключе в условии.

## 5. Фальсифицируемость гипотез

Каждая гипотеза оформляется как предсказание: «если страна X, то знак Y выглядит как Z, номер — формат W, язык вывесок — V». Проверь ВСЕ предсказания. Счёт подтверждений в STATE: `гипотеза | за | против`. Решение — при 5+ независимых «за» и 0 неопровержимых «против». Противоречие → гипотеза мертва, даже если она «красивая».

## 6. Инструменты окружения

- `web_search` (включён агенту) + `WebFetch` для чтения страниц; интерактив — browser MCP / playwright-cli.
- WSL Kali: exiftool, whois, dig, curl; python для расчёта теней/координат.
- Все внешние запросы — только по цели задачи; артефакты не загружать на сторонние сервисы без явного разрешения условия.

## 7. Сенсорные шаги — петля с оператором

Агент не видит изображений и не слышит аудио — «посмотреть на фото» он не может, а выдумывать содержимое по имени файла запрещено. Любой сенсорный вопрос решается петлёй с оператором, а не догадкой:

1. **Подготовь артефакт сам** — не проси оператора «посмотреть оригинал». Вырежи и усили интересное: `ffmpeg -ss 12 -i v.mp4 -frames:v 1 -vf "crop=400:120:880:600,scale=400%" q.png`, для фото — `convert in.jpg -crop WxH+X+Y +repage -resize 300% -normalize q.png`, для аудио — `ffmpeg -i a.mp3 -ss 30 -t 10 frag.wav` + спектрограмма.
2. **Приложи артефакт к сообщению** и задай **один конкретный вопрос** с вариантами, а не «что тут?»: «На приложенном кропе номерного знака: первые символы — A12 или АИ2? Кириллица или латиница?»
3. **Ответ оператора = факт.** Записывай в FACTS с источником `оператор, кадр N / фрагмент M` и трактуешь как одно подтверждение §5 (не как истину в последней инстанции — оператор тоже ошибается, сомнительное переспроси на другом кропе).
4. Вопросы пачками не задавай: 1 артефакт → 1 вопрос → ответ → следующий. Так оператор не устаёт и ответы остаются проверяемыми.
5. **Аудио-дорожки (что играет)**: сначала сам — спектрограмма на скрытый текст (§3 stego-workbench), `strings` на теги; опознание трека — оператор (Shazam/audiotag.info на своей стороне). Мелодия-морзе/DTMF — декодируй сам (python), не оператором на слух.

Плохо: «посмотри картинку и скажи, что на ней». Хорошо: «кроп номера увеличен ×4 — какая буква первая?»

## 8. Анти-тупик

- Нет фактов из артефакта → перечитай условие: в osint-задачах данных всегда достаточно, «недостающее» прячется в описании (имя, дата, намёк на сервис).
- Застрял на стране → собери чек-лист §2 полностью, а не первые 3 пункта.
- Найденное место/имя без 5+ подтверждений не выдавай за ответ; зафиксируй в STATE и продолжай сбор.
- Два круга без прогресса — зафиксируй тупик, возьми перерыв-ветку (другая подзадача), вернись со свежей таблицей FACTS.
