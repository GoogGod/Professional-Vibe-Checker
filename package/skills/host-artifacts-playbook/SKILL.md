# Хостовые артефакты — тактика и кейсы

Скилл для задач про **артефакты хоста**: бинарники Windows, дампы памяти, трафик, диски, контейнеры. Обобщённый опыт архивных серий; не привязан к конкретному соревнованию. Флаги не хранятся.

## 1. Windows revers (в т.ч. NativeAOT и инжекции)

- **Кейс: DLL/EXE с инжекцией в системный процесс** (например, NativeAOT-DLL + загрузчик).
  - Точная версия окружения критична (ОС + версия целевого приложения): сначала зафиксируй её из README/заметок, потом воспроизводи.
  - Загрузчик может содержать **байтовые патчи** (снятие проверок по конкретным адресам) и **хуки icall** (перехват внутренних вызовов рантайма), обработку исключений (SEH).
  - Динамика: Frida-скрипт на целевой процесс — перехват нажатий/проверок, дампы аргументов; в логах ищи формирование итоговой строки (она может собираться по частям).
  - Статический разбор: IDA/Ghidra; символы NativeAOT ограничены — опирайся на строки и трассы icall.
- **Общие правила**:
  - Неизвестные исполняемые файлы **не запускай на хосте** — изолированная среда (VM) и только после статического анализа.
  - Сохраняй журналы (loader.log и пр.); «почти-флаги» из логов — только кандидаты: продолжай трассировку до полного значения.
  - Патчи и хуки воспроизводи по шагам, с проверкой каждого (patch → run → check).

## 2. Дампы памяти Linux

- **LiME-дампы** (формат `lime`): volatility3 → `banners`, `pslist`/`psscan`, `malfind`, `bash` history, env, сокеты; ищи секреты и следы скрытых процессов.
- Большие дампы (4+ ГБ): сначала быстрый скан профилей и списков процессов, затем точечно — память конкретных процессов.
- Полезно: сравнение «до/после»; таймстемпы; сопоставление с трафиком.

## 3. Трафик (выгрузки и pcap)

- Выгрузки HTTP-запросов/ответов (в т.ч. с URL-кодированными именами файлов): реконструируй **сессию пользователя** по цепочке запросов (login → upload → draft → download и т.п.).
- Определи фреймворк фронта (по ассетам вида app.js/buildManifest) и ищи типовые уязвимости этого стека; проверяй Next.js/RSC-цепочки по свежим CVE.
- pcap большие: `tshark` (протоколы, объекты, потоки), фильтры по полям; извлекай объекты (`--export-objects`); при TLS — ищи ключи/дампы в других артефактах.
- Ищи утечки: токены, cookie, внутренние адреса, аномальные ответы.

## 4. Диски, образы, контейнеры

- **Сигнатуры прежде всего**: zip может оказаться 7z/rar/дисковым образом; `file`, hex-заголовки, `binwalk`.
- **LUKS/шифрконтейнеры**: заголовок (LUKS2, aes-xts-plain64, argon2id) читается из сырых данных; ключевой материал ищи в соседних артефактах (pcap, тексты, образы).
- **Файловые системы / FAT**: sleuthkit (`fls/mactime/istat/blkcat`), mtools (`mdir/mcopy`), foremost/photorec (осторожно с вклейкой JPEG). Карвинг по маркерам свободных кластеров + донорские структурные блоки той же версии ПО.
- **Autopsy/USN**: журналы USN, артефакты Windows (`desktop_1_files/usn`) — таймлайны действий.
- Работай на **копиях** образов; все находки — в `STATE.md` с таймстемпами в UTC.

## 5. Инструментарий (сводно)

- Windows: x64dbg, IDA/Ghidra, Frida, Process Monitor; Python-стек.
- WSL/Linux: volatility3, tshark/tcpdump, sleuthkit, mtools, foremost, binwalk, exiftool, 7z/unrar, cryptsetup.
- Установка и грабли — в `win-wsl-ctf-workbench`.
