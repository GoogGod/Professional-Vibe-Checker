# Крипто-солверы — архив рецептов

Архив решённых крипто-задач и проверенных подходов. Обезличен: не привязан к конкретному соревнованию. Флаги не хранятся. **Паттерн работы**: читай условие (`TASK*`) → код шифрования → ищи слабость → подбери/адаптируй солвер → **валидируй на синтетике** → применяй.

## 1. Семейства и подходы

- **Subset-sum / knapsack** (например, Merkle–Hellman): решётка или жадные эвристики; проверь размерность и плотность.
- **Урезанные блочные шифры**: неполные раунды → алгебраизация или перебор остатка раундов; ГОСТ «Магма» с усечением (3 раунда) → восстановление по слабости расписания.
- **ElGamal с большим датасетом** (~600 KB выходов): статистика/повторы, малые подгруппы, утечка nonce.
- **Классический RSA**: факторизация при слабых p/q, общий модуль, малые экспоненты, Hastad, Франклин-Рейтер, паддинг-оракулы.
- **Решёточные атаки на RSA**:
  - малый d → **Wiener** (цепные дроби);
  - чуть выше границы → **Boneh–Durfee** (Herrmann–May: xy→u−1, y-сдвиги; LLL с `gram='exact'` в python-flint);
  - блочные утечки по 8 байт → **CJLOSS**-решётка + LLL→BKZ-20 (fpylll).
- **LWE + LCG-шум**: восстановление seed генератора (решётка + вложение Каннана, ~25 измерений, sympy LLL) → поток → вычитание шума → линейная система (Гаусс по mod q).
- **ECC-экзотика**:
  - аномальная кривая (#E=p) → **Smart's attack** (p-адический лифт);
  - supersingular → **MOV** + distortion map + Pohlig–Hellman (в т.ч. перебор кофакторных лифтов при большом h);
  - invalid curve → подбор b′ (CM: p≡1 mod 3, Корначчи 4p=t²+3v²), порядки твистов, PH+BSGS+CRT+перебор.
  - Внимание: проверяй, не приманка ли часть этапов (decoy-цепочки бывают).

## 2. Приёмы «обвязки»

- Каскады: PIN → sha256(pin)[:16] как ключ AES; кастомные паддинги (byte = число блоков; циклические сдвиги по сумме цифр); ECB/CTR-особенности.
- «Матаппарат-декорация»: в описании может быть бутафория (экзотическая терминология) — истинная логика в коде: полиномиальные обновления по mod p, линейные рекурренции и т.п.
- Jigsaw: RANSAC по точкам, извлечённым из изображения (эрозия, фильтры), forward-search по модулю, и только затем KDF (scrypt) на найденных прообразах.
- PDF/контейнеры: сырые данные после %%EOF, перебор cipher suites и дериваций, объекты и метаданные.
- Anchor-подход: кластеры символов вокруг известного префикса формата флага; Caesar-сдвиги; десятичные «станции».
- **Оракул-каскад на кастомном блок-шифре**: если есть оракул `decrypt(key, block, iv)` и известна диффузия IV — «изменение `iv[k+1]=0/1` меняет только половину выхода (правую при чётном k, левую при нечётном)» — восстанавливай ключ посимвольно: парные запросы кандидата h (совпадение половины выхода) → DFS по байтам k=0..n−1 (1–3 кандидата на уровень); последний байт — через известное тождество (например, `D(key,0,key)=0`); финальная верификация на случайных парах против локальной референсной реализации.
- **LFSR с известным префиксом**: xor префикса флага с шифротекстом → первые 64 бита keystream → **Berlekamp–Massey** → минимальная рекурренция (порядок ≈ длина регистра) → продолжение keystream → расшифровка.
- **DH-MITM с подменой `B'=1`**: получатель принимает точку `B'=1` → общий секрет = 1 → ключ `sha256(1)` и т.п.; дальше стандартная подмена `A'`/`B'`. Эфемерный ключ на соединение → весь протокол (все запросы + сабмит) в ОДНОМ соединении; массовые запросы шли батчем (один буфер) вместо round-trip.

## 3. Стек инструментов

- **WSL**: `fpylll` + `flint` (LLL/BKZ; всегда `gram='exact'` на больших числах), `sympy` (LLL-lite, алгебра), `sage` (тяжёлая артиллерия — ставить отдельно), `pwntools` (серверные задачи).
- **Python**: `pycryptodome`, `gmpy2`, `numpy`; свои скрипты — в `toolbox/` пакета с именами `solve_*`.
- Валидация: синтетический инстанс с известным ответом обязателен для решёточных/вероятностных атак.

## 4. Чек-лист перед атакой

1. Параметры: n/e/d/β, размерность, q, порядок группы, кофакторы — выпиши в `STATE.md`.
2. Сверь реализацию с канонической: где отклонение — там вектор.
3. Выбери атаку по границе применимости (таблицы границ: Wiener < Boneh–Durfee < полный разбор).
4. Прогони на синтетике; оцени время (минуты/часы) и память.
5. Только потом — на боевых данных; промежуточные результаты сохраняй.

## 5. Куда сохранять опыт

- Новый рабочий солвер → `toolbox/` + запись в `lessons/` (см. `hermes-knowledge-loop`).
- Устойчивые рецепты — обновляй этот скилл; общие кейсы — в `ctf-lessons-corpus`.
- **Флаги не генерировать** (в том числе «для отвода внимания»); найденные значения — только в локальных записях с пометкой, не в скиллах/пакете.

## Готча (ловушки)
- После base64-decode получился «шифртекстоподобный» мусор → сначала проверь кастомный base64-алфавит (длина ключа+строки кратна 64), и только потом гадай шифр.
- subset-sum/knapsack: веса бывают со знаком; цель ≠ длина массива. Сначала проверь подмножество минимального размера.
- RSA: начинай с малых e (e=3, Håstad) и gcd двух шифртекстов одного сообщения, потом Wiener/Boneh-Durfee.
- Решётки: нормируй размерность и модуль (CJLOSS); срыв-бэнд = неправильный scale фактор.
