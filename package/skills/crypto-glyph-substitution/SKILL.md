# Визуальный шифр на глифах (подстановка по биграммам + частотный анализ)

## Признаки задачи
- PDF/изображение содержит сетку повторяющихся растровых символов (эмодзи, пиктограммы, формы, глифы Type3/Form XObject) — тысячи позиций.
- Рядом (другой лист/часть) — легенда: ограниченный набор пар «глиф → символы/буквы» (часто 10–15 пар).
- В том же документе — таблица частот символов алфавита/биграмм текста.
- Флаг: `hash(русское_слово)` или `hash(слово)`.
- Текст рассказа — сплошная строка без пробелов.

## Модель (типовая)
1. Единица шифрования — НЕ буква, а ПАРА букв (биграмма): один глиф = одна биграмма.
2. Моноалфавитная подстановка: один глиф = одна и та же биграмма во всём тексте.
3. Пробелы выброшены.
4. Легенда даёт ~12 пар (начальная зацепка), остальные сотни глифов нужно восстановить по частотам.

## Алгоритм
1. Извлечь глифы из PDF: растеризовать Form XObject/Type3 по одному; кластеризовать попиксельно (NCC, гистограмма цветов, хэш уменьшенного изображения). Точное число классов = размер алфавита шифра.
2. Считать частоты каждого уникального глифа в сетке.
3. Сопоставить частоты глифов с таблицей частот биграмм (если дана) — сортировка по убыванию, частые глифы = частые биграммы.
4. Наложить известные пары из легенды.
5. Развернуть текст; применить языковую модель (словарь форм/слов) для подбора оптимального маппинга и проверки осмысленности.
6. Прочитать ВЕСЬ текст полностью (тысячи знаков) — не останавливаться на первых строках.

## Целевое слово
- Если флаг — `hash(слово)`: ищи слово, которое семантически «выпадает» из ряда (редкое, неочевидное), а НЕ самое частое/заголовочное слово.
- Собери 5–10 кандидатов из ПОЛНОГО текста (частые темы + редкие слова), посчитай hash всех, сдавай кандидата с подтверждением из контекста (обычно валидатор принимает ровно один).
- НИКОГДА не сдавай первый очевидный кандидат (заголовок, первое слово) без проверки остальных.

## Грабли
- Не пытаться OCR-читать глифы как буквы/QR — это растровые формы, нужна пиксельная кластеризация.
- Заголовок страницы ≠ слово-ответ (это тема задачи).
- Таблица частот рядом с легендой — ЧАСТЬ КЛЮЧА, не игнорировать.
- 12 пар легенды — лишь затравка; без восстановления остальных ~480 биграмм текст не прочитается.
- Для русских текстов: словарь форм слова (1+ млн), а не только частота букв.
