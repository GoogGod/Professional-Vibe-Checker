# Stego Workbench — конвейер, а не разглядывание

Модель не «видит» картинку. Но она читает **текст (OCR)** и **числа**. Конвейер превращает стего-носитель в текст и числа; закономерности ищутся сравнением значений, а не визуально. Каждый шаг фиксируй в STATE — включая отрицательный результат.

## 1. Identify — всегда первым

```sh
file carrier.*            # истинный формат против расширения
binwalk -e carrier.*      # встроенные/прикреплённые данные, карвинг
exiftool -a -u -g1 carrier.*   # ВСЕ метаданные (комментарий, GPS, XMP, maker notes)
strings -n 6 carrier.* | head -100
python3 -c "import math;..."  # энтропия/размер (см. §5)
```

- Хвост после маркера конца: JPG — данные после `FFD9`, PNG — после `IEND` (проверь `binwalk`/hex-просмотр конца файла).
- Несостыковка declared vs actual размер/пропорции — записать в STATE.

## 2. Изображения — по формату

**PNG/BMP (без потерь → вероятен LSB):**
- `zsteg -a file.png` — все планы/каналы/порядки битов сразу; сохранить полный вывод.
- Бит-планы в картинки + OCR (главный приём для «невидимого» текста):

```python
from PIL import Image
im = Image.open('f.png'); px = im.convert('RGB'); w, h = px.size
for ch in range(3):
    for bit in range(3):  # младшие 3 бита на канал
        out = Image.new('1', (w, h))
        po = out.load()
        for y in range(h):
            for x in range(w):
                po[x, y] = ((px.getpixel((x, y))[ch] >> bit) & 1) * 255 > 0
        out.save(f'plane_c{ch}_b{bit}.png')
```
Затем: `tesseract plane_c0_b0.png stdout` по каждому файлу. Мелкий/бледный текст не читается без подготовки: `convert plane.png -resize 400% -threshold 50% big.png` → tesseract на big.png (для сплошного текста `--psm 6`).
- Палитровые PNG/GIF: уникальных цветов подозрительно мало? Декодер палитры в 1-битные маски (тот же приём).
- **Слепые зоны zsteg** (порядок пикселей ≠ растровый): column-major, побитная сборка msb-first, канал целиком, альфа-канал RGBA, 2-й/3-й бит. Не перебирай руками — скрипт `toolbox/lsb_harvest.py` из базы пакета:

```sh
python3 lsb_harvest.py f.png --show 3    # перебор order/каналы/бит/msb — топ по printable+magic, hexdump
python3 lsb_harvest.py f.png --runs      # серии >=8 по плоскостям: аномалия = вложение
python3 lsb_harvest.py f.png --extract row,RGB,0,lsb,8192 > payload.bin
```

**Альфа-канал как КАРТА (механика полевого solve 2026-10-23):** константная альфа + N аномальных пикселей — аномалия не данные, а карта: LSB-биты RGB ровно отмеченных пикселей, row-major, interleaved, msb-first. zsteg/lsb_harvest слепы (полезные 102 пикселя тонут в миллионе фоновых). Детект в одну строку (`np.unique(px[:,:,3], return_counts=True)` — ровно 2 значения, одно на порядки реже), затем `toolbox/alpha_lsb.py` — авто-батарея порядков/каналов/битости + `--expect "префикс{"` (exit 0). Сверка длины: N пикселей ×3 бит = длина payload. Детали: `lessons/2026-10-23-stego-alpha-map-lsb.md`.

**JPG (с потерями → прятать в LSB нельзя, значит контейнер/пароль/мета):**
- `stegseek file.jpg /usr/share/wordlists/rockyou.txt` (steghide-брут; перебор по SecLists passwords тоже).
- exif-поля, встраивание в превью/thumbnail, append после `FFD9`.
- `outguess -r file.jpg out.txt` при ключе из условия.

**GIF/WebP:** разложить кадры `ffmpeg -i f.gif frame_%03d.png`; аномальные задержки кадров (`exiftool` по кадрам); WebP → конвертировать в PNG и пройти §PNG.

**Каждое изображение:** `tesseract f.png stdout` на оригинал тоже (видимый мелкий текст/водяные знаки).

**PDF/офис-документы:** `qpdf --qdf in.pdf out.pdf` + `mutool show in.pdf` (потоки-объекты, скрытые слои); OOXML (docx/xlsx/pptx) — это zip: `unzip -l`, смотреть `word/media/`, `docProps/`, `xl/media/` — вложенные картинки прогоняются как отдельные изображения §2.

## 3. Аудио

```sh
sox in.wav spectrogram -o spec.png -x 1600 -y 800   # и по каналам: sox in.wav spectrogram ... split? (ffmpeg -i in.wav -ac 1)
tesseract spec.png stdout                            # текст в спектрограмме - частый кейс
```
- Стерео-дисбаланс: вычесть каналы (`sox -m in.wav in.wav -V1 diff.wav` с инверсией) — прячут в разнице каналов.
- Морзе/DTMF: `multimon-ng -a morse` / `-a dtmf`.
- WAV: `binwalk`, LSB в сэмплы (`python`+`wave`, тот же бит-план).
- Смотреть и на осциллограмму (тихие участки с формой).

## 4. Видео

- Кадры: `ffmpeg -i v.mp4 frame_%04d.png` → diff соседних кадров (python, порог) — кадры-вставки.
- Звуковая дорожка отдельно (`ffmpeg -i v.mp4 -vn a.wav`) → §3.
- **Информация в гейплее/UI = числа → ASCII → самопроверка префиксом флага из условия.** Три проверенные механики:
  - **HUD-счётчики** (очки/монеты в конце забега): `ffmpeg -sseof -3 -i v.mp4 -vf fps=2 tail/%04d.png`, OCR зоны счёта (`tesseract tail.png stdout --psm 7 -c tessedit_char_whitelist=0123456789`); N забегов → N чисел → `chr()`.
  - **Почти-чёрный текст в кадрах**: `ffmpeg -i in.mp4 -vf "fps=1,eq=brightness=0.06:contrast=3" f%04d.png` (или порог point x>8→255) → OCR/просмотр.
  - **Цветовые события** (объекты двух цветов, один — разделитель): `toolbox/video_color_events.py` из базы пакета — HSV-порог, трекинг блобов между кадрами, счёт по сегментам, ASCII-декод с `--expect "префикс{"` (exit 0 = префикс сошёлся). Пример: `python3 video_color_events.py --video v.mp4 --hsv 0,150,80 14,255,255 --sep-hsv 33,120,80 48,255,255 --expect "CTF{"` (H-шкала 0-255; красный живёт в двух зонах — 0-14 и 245-255). Смоук-тест: 5162 кадра, 429 объектов → точный счёт и декод за 27 с.
- Визуальную аномалию на кадрах (приборы, панели, артефакты), которую не формализовать порогом, подтверждает оператор: приложи к сообщению топ-5 аномальных кадров и один конкретный вопрос.

## 5. Числовые признаки — отдай модели на анализ

Собери и запиши рядом (это вход для вывода закономерностей, который модель реально умеет делать):

- энтропия по каналам/планам (норма ~7.9 для фото, выше — доп. сжатие/шифр);
- доля единиц в LSB каждого канала (норма ≈ 0.5; заметное отклонение = вложение);
- метрика длинных серий бит по плоскостям (`lsb_harvest.py --runs`): у чистого фото серии короткие, текстовый/структурный payload даёт аномально длинные;
- zsteg verbose: chi-square-статистика по планам;
- гистограмма: обрезанные/пустые младшие значения;
- количество уникальных цветов; размеры payload-кандидатов из binwalk;
- список строк-кандидатов с кодировками (base64/hex/морзе-паттерны).

Правило вывода: две гипотезы сравниваются числами, а не «показалось».

## 7. AperiSolve (опционально, только при разрешённом интернете)

Веб-сервис, агрегирующий zsteg/exif/binwalk/steghide и др.: загрузить файл на `https://www.aperisolve.com` → агрегированный отчёт. Полезен как второе мнение/быстрая проверка, но офлайн-конвейер (§1–§6) самодостаточен и основной.

## 8. Анти-тупик

- Стего без явного ключа в условии почти всегда = LSB / append-данные / спектрограмма / метаданные — иди по конвейеру сверху вниз.
- Два круга без результата: перечитай условие (что «дано» — намёк на метод), проверь другой тип контейнера (тот же файл как архив/zipjpg), зафиксируй тупик и смени категорию.

## Готча (ловушки)
- zsteg/lsb_harvest слепы к «картам»: альфа 255 кроме N аномальных пикселей → данные в LSB RGB именно этих (alpha_lsb.py).
- PNG-фильтры (IDAT) маскируют простое LSB — сначала unfilter (pngcheck/zlib), потом бит-планы.
- JPEG-стего — не LSB: смотри DCT-коэффициенты (stegdetect/jsteg).
- Флаг может жить в EXIF/комментариях: `exiftool -a` до бит-планов.
