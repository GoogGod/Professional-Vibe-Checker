# Web: инъекции, SSRF, XSS+бот — тактика

Когда применять: веб-сервис с обработкой пользовательского контента,
headless-ботом, загрузкой файлов или нестандартными форматами.

## Порядок действий
1. Отметить **весь пользовательский контент**, попадающий в шаблон/строку:
   имя, ник, сейв, загружаемый файл → пробовать SSTI `{{7*7}}`, затем
   `__class__.__mro__[1].__subclasses__()` → RCE. `lessons/2026-11-01-web-ssti-pokebox-savefile.md`.
2. **Mass assignment / NoSQL**: JSON-объекты → `__raw__`, скрытые поля
   (`admin`, `role`). `lessons/2026-11-01-web-mass-assignment-mongoengine.md`.
3. **SSRF → внутренний сервис → тикет → RCE → реплей протокола** (multi-stage):
   сначала составить карту переходов, потом эксплуатировать.
   `lessons/2026-11-01-web-hiddennetwork-ssrf-ticket-s1ap.md`.
4. **XSS + headless-бот**: goal — заставить бота (credentials:include) отдать
   флаг/приватное; пейлоад — одна версия (LIFO), интервалы прихода бота;
   используй DOM-дамп с фильтром по префиксу флага. `lessons/2026-11-02-web-fallback-bot-secret-visit.md`.
5. **Codec confusion / JSON-as-script / srcdoc**: интерпретация контента в
   другом контексте (image→HTML, JSON→script), same-origin.
   `lessons/2026-11-01-web-codec-confusion-xss-srcdoc.md`.

## Грабли
- Бот приходит редко — сначала тайминг, потом пейлоад.
- Если права не применяются от твоего имени — ищи другого user'а/тикет.
- Очередь применения: по одному действию за сообщение, критичные первыми.
