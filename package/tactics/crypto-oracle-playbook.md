# Crypto: оракулы и восстановление ключей — тактика

Когда применять: сервис принимает шифротекст и отвечает «да/нет» или
выдаёт расшифрованный/проверенный результат (padding, LSB, parity,
каскадный оракул, ECB-словарь, digest-коллизия).

## Порядок действий
1. Определить тип реакции: `padding error` vs `incorrect`, бит ответа,
   разница во времени, длина ответа.
2. **CBC padding oracle** — классический побайтовый взлом: блок за блоком,
   `pad = 0x01..0x10`, подбор последнего байта, затем сдвиг. Скрипт-эталон:
   `lessons/2026-11-03-cbc-padding-oracle-devglan.md`.
3. **RSA LSB/parity oracle** — перебор границ `m` бинарным поиском по ответу
   на `C * 2^e mod N`. Эталон: `lessons/2026-11-01-rsa-lsb-oracle.md`.
4. **Каскадный оракул** (свой блок-шифр): «изменение одного входа меняет
   только один байт» → парные запросы снимают неоднозначность; последний
   байт через тождество. Пример: `lessons/2026-10-30-polyphemus-oracle-cascade-key-recovery.md`.
5. **ECB-словарь** — блоки как карты: повторяющиеся блоки + побайтовый
   подбор. Digest-«сумма байтов mod N» — кандидаты по остатку.
   `lessons/2026-11-01-block-cipher-structures-ecb-oracle-digest-collision.md`.
6. **DH/дискретный логарифм**: маленький секрет → BSGS (`≤2^32`).
   `lessons/2026-10-29-dh-small-secret-bsgs.md`.

## Грабли
- Сначала подсчитать, сколько запросов сервис отдаёт на одно соединение.
- Ловить «успех» не только по статусу, но и по длине/состоянию.
- Все числа парсить в правильной системе счисления (base-8, base-16).
