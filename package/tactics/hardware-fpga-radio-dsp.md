# Hardware/FPGA, радио, DSP — тактика

Когда применять: битстримы ПЛИС, Verilog-нетлисты, сэмплы сигналов,
чёрные ящики-трансмиттеры.

## Порядок действий
1. **FPGA iCE40**: битстрим → `iceunpack` → `icebox_vlog` → анализ логики;
   искать регистры/счётчики/константы, связанные с флагом.
   `lessons/2026-11-01-hardware-fpga-ice40-bitstream-21centuryman.md`.
2. **Verilog/симуляция**: восстановить нетлист, сэмулировать, перехватить
   сигналы (данные, разрешения). `lessons/2026-11-01-hardware-fpga-verilog-sim.md`.
3. **Радио/DSP**: сигнал — сэмплы; сначала построить спектр/огибающую,
   понизить частоту до baseband, детектировать модуляцию (chirp → FSK/PSK),
   сравнить с эталоном, проверить наличие сообщений на несущих/в паузах.
   `lessons/2026-11-01-radio-dsp-chirp-blackbox-transmitter.md`,
   `lessons/2026-11-01-dsp-vm-reverse-noise-in-space.md`.

## Грабли
- В blackbox-тасках сначала калибровка по известному входу.
- Сэмплы могут содержать несколько сигналов/несущих — разделять.
- Не путать «шум» с полезным сообщением: искать корреляцию с флагом.
