# Мобильная форензика: APK и артефакты — тактика

Когда применять: Android-приложения, бэкапы телефона, дампы БД.

## Порядок действий
1. **APK**: распаковать (zip), декомпилировать (jadx/apktool); искать
   скрытые строки, активности, обработчики.
2. **SharedPreferences / sealed-prefs / EncryptedSharedPreferences**: ключи
   могут лежать в предпочтениях или в переданном seal-векторе — сравнить
   открытый и закрытый форматы. `lessons/2026-11-01-mobile-apk-sealed-prefs-ghostvector.md`.
3. **Stateful-крипта**: состояние (nonce/seed) хранится в приложении и
   меняется от запуска к запуску — воспроизвести последовательность.
   `lessons/2026-11-01-mobile-apk-stateful-crypto-meowsim.md`.
4. **SQLite / .dex / дампы**: вытащить БД, логи, DEX-классы; искать флаг
   по полям и строкам. `lessons/2026-11-01-mobile-forensics-burnt-note-sqlite-dex.md`.

## Грабли
- Не доверять названию файла — проверять магию/формат.
- Sealed-prefs: имя префа может быть эвристикой для ключа.
- Состояние приложения (seed/nonce) часто воспроизводимо — не нужно брутить.
