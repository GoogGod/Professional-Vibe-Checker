# Flags — политика

- **Генерация значений флагов запрещена всегда** (анти-галлюцинация): ни заглушки, ни «примерно», ни «для отвода внимания».
- **Публичный пакет/репозиторий значений не содержит**: агенты не должны принимать исторические значения за ответы текущих задач.
- **Локально можно**: в рабочих файлах сессии и в локальной копии записи урока значение фиксируется с явной пометкой «значение конкретной задачи; НЕ ответ для других задач».
- Формат флага агент берёт как прообраз из условия **текущей** задачи.
- Гигиену проверяет `../tools/check_package.ps1` (CI сканирует всё, включая `lessons/`).
