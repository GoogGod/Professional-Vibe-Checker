# Changelog — переносимый пакет Red Team оператора

Формат: версия — дата — кратко. Все изменения фиксируются; старые записи не удаляются.

## 0.5.2 — 2026-10-20

- `toolbox/video_color_events.py`: детектор цветовых событий в видео — HSV-порог, векторизованный трекинг блобов между кадрами (run-length через np.diff + union-find), счёт по сегментам с цветом-разделителем, ASCII-декод с `--expect` (exit 0 = префикс флага сошёлся). Смоук-тест: 5162 кадра, 429 объектов — точный счёт и декод за 27 с.
- `stego-workbench` §4 (видео): три проверенные механики — HUD-счётчики (`ffmpeg -sseof` + tesseract digits → chr), почти-чёрный текст (eq/threshold + OCR), цветовые события (`video_color_events.py`); принцип «геймплей = числа → ASCII → самопроверка префиксом»; визуальные аномалии подтверждает оператор (топ-5 кадров + один вопрос).
- `osint-workbench` §7: сенсорная петля с оператором — агент сам готовит артефакт (кроп/усиление/фрагмент), прикладывает к сообщению, задаёт один конкретный вопрос; ответ = факт в FACTS с источником «оператор, кадр N». Аудио: морзе/DTMF декодируй сам, опознание трека — оператор (Shazam/audiotag.info).
- CHANGELOG: восстановлена читаемая кодировка (файл был двойнокодирован), добавлены пропущенные записи 0.5.0/0.5.1.

## 0.5.1 — 2026-10-20

- `toolbox/lsb_harvest.py`: багфикс скоринга — префиксное окно (16..4096 Б) вместо усреднения по всему буферу; короткие полезные нагрузки больше не тонут в хвостовом шуме. Слепое извлечение подтверждено смоук-тестом (параметры найдены перебором, текст извлечён).

## 0.5.0 — 2026-10-20

- Новый скилл `osint-workbench`: детерминированный конвейер OSINT — артефакт-паспорт (exiftool/binwalk/strings), чек-лист геолокации из 10 признаков + расчёт теней (`tan(alt)=H/L`), ники, инфраструктура (whois/crt.sh/wayback/операторы поиска), фальсифицируемость гипотез (5+ независимых подтверждений, таблица «за/против»).
- `stego-workbench`: слепые зоны zsteg закрыты тулзой `toolbox/lsb_harvest.py` (column-major, msb-first, биты 2-3, alpha); OCR-подготовка (resize 400% + threshold, `--psm 6`); ветка PDF/OOXML; метрика runs по бит-планам.

## 0.4.2 — 2026-10-20

- `hermes-knowledge-loop`: локальный контур writeback `local/` в базе знаний — уроки/тактики/скрипты агентов установленного harness переживают обновления пакета; публичная часть базы объявлена read-only для агентов, продвижение в пакет — отдельный шаг с `check_package.ps1`.
- `tools/sync_package.ps1`: новый параметр `-KBTarget` — зеркалирование knowledge-base robocopy /MIR с сохранением `local/` (/XD local); вызов без параметра не меняет поведение.

## 0.4.1 — 2026-10-20

- `revshell-arsenal`: полная шпаргалка однострочников (bash/mkfifo/python3/php/perl/powershell/powercat) + порядок работы; рамки — только авторизованные цели.
- `linux-privesc`: §2 переписан — локальная копия linPEAS в Kali (`/usr/share/peass/linpeas/linpeas.sh`), обновление с GitHub-releases, лицензионная пометка.

## 0.4.0 — 2026-10-20

- Новые скиллы: `ida-workbench` (headless IDA Pro через IDAPython — реверс как tool-call: recon/декомпиляция/xrefs), `stego-workbench` (детерминированный стего-конвейер: бит-планы + OCR + числовые признаки; AperiSolve — опциональная ветка), `revshell-arsenal` (методика обратных шеллов для авторизованных целей; пейлоады — через генераторы), `linux-privesc` (ручная методика + linPEAS + GTFOBins-интерпретация).
- `ctf-router`: маршрутизация дополнена (reverse→ida-workbench, forensics/stego→stego-workbench, pwn-пост-эксплуатация→revshell-arsenal/linux-privesc, пивоты).
