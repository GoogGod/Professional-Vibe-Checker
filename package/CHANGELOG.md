# Changelog — переносимый пакет Red Team оператора

Формат: версия — дата — кратко. Все изменения фиксируются; старые записи не удаляются.

## 0.3.0 — 2026-10-18

- Репозиторий упрощён до чистого модуля: удалены eval-комплект (A/B) и docs.
- README переписан как инструкция подключения модуля (релиз → скиллы в harness → промпт → задача).
- Устранён архитектурный разрыв из полевого теста: скиллы доступны **прямым чтением файлов** — работа без инструмента `Skill`; внешние инструменты (WebFetch и др.) опциональны.
- Петля hermes согласована с принципом «только важное»: пустой writeback — норма; мусор хуже пустоты.
- CI: только гигиена пакета.

## 0.2.0 — 2026-10-18

- Пакет стал самодостаточным: включена **библиотека категорийных скиллов** `library/skills/` (ctf-*, solve-challenge, os-*).
- Добавлены `VERSION` и `CHANGELOG.md`.
- Обновлены `START-HERE.md` (состав, проверка целостности) и скилл `ctf-router` (ссылка на библиотеку внутри пакета).
- Уточнена политика флагов: значения не хранятся в пакете; генерация запрещена (в т. ч. «для отвода внимания»).

## 0.1.0 — 2026-10-18

- Первая переносимая редакция: `system-prompt.md`, 8 авторских скиллов `skills/`, база знаний (`lessons/`, `tactics/`, `toolbox/`, `flags/` — только политика), `START-HERE.md`, `README.md`, `index.md`.
- Обезличенный импорт корпуса решённых задач в `lessons/`.
