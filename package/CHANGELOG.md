## 0.5.8 — 2026-10-23

Три полевых solve подряд (easy web-брут 5 мин; hard стего 10 мин; hard реверс PyInstaller 2ч08м) — протокол П1-П6 исполнен во всех, уроки агентами записаны в local сами.

- Новый тулз `toolbox/alpha_lsb.py`: альфа-канал как карта + LSB отмеченных пикселей — авто-детект аномальной альфы, батарея порядков/каналов/битости, printable-скоринг, `--expect` самопроверка. Смоук на полевом файле: победитель row/RGB/msb ratio 1.00, префикс сошёлся, exit 0.
- Урок `lessons/2026-10-23-stego-alpha-map-lsb.md` (деперсонализовано): механика, детект одной строкой, сверка длины N×3бит, обобщение («почти константный» канал = кандидат в карту).
- Урок `lessons/2026-10-23-pyinstaller-cursed-python.md` (деперсонализовано): CArchive/PYZ-парсер своими руками (грабли pyver=313), скрэмблинг опкодов и калибровка таблицы блэкбокс-микропрограммами, sidecar-инъекция в bootloader, per-symbol constraint solving вместо реверса логики (fnv1a32, амбигентная позиция — вопрос оператору).
- `stego-workbench` §2: блок «Альфа-канал как КАРТА» со ссылкой на тулзу и урок.

## 0.5.7 — 2026-10-22

По итогам решённого поля (medium web, XSS+headless-бот, 40 мин, протокол П1-П6 исполнен полностью):

- `browser-bot-bridge`: §3 — правило base64-обёртки для JS в URL навигации бота; §4 — три полевые ловушки: амперсанд-ловушка (`&` рвёт query, пейлоад обрывается), «окно бота = одна версия пейлоада» (LIFO-очередь, интервал 30 с – 10 мин: сначала измерить тайминг зондами, первая XSS-версия — максимальный дампер с grep по префиксу флага, не минимальный проб), webhook-PATCH может отказать (запасной paste.rs, но text/plain не годится для DOM-парсинга бота).

- `ctf-router` П5: уточнение — в чате фоновая задача Bash уже даёт параллельность; spawn_task — для длинных независимых веток.

## 0.5.6 — 2026-10-22

- `ctf-router`: **финальный ⛔ BOOT-ПРОТОКОЛ** — П1 «карта возможностей» (зафиксировать доступные скиллы/инструменты/окружение до первого действия — принцип «сначала изучи свои возможности»), П2 маршрут + SKILL.md целиком, П3 чужой опыт (local/index.md → lessons → vuln-notes), П4 план в TodoWrite с точками оператора и фиксации урока, П5 дисциплина (одна строка / 15 минут / cve-scout по фингерпринту), П6 финал с врайтбеком.
- Новый скилл `cve-scout`: триаж «нужен ли CVE-путь за 30 секунд» (ДА/НЕТ-критерии), порядок источников от дешёвого к дорогому (vuln-notes → NVD 2.0 → cveawg → GitHub Advisory/PoC), путь от CVE к делу (диапазон → предусловия → детект → эксплойт), обязательный учёт эффективности: `hits:N` при успехе, `нет: <причина>` при опровержении.
- `local/toolbox/vuln-notes.md`: формат расширен колонкой `hits` (агенты инкрементируют при успешном применении — статистика «что реально помогало»).

## 0.5.2 — 2026-10-20

- `toolbox/video_color_events.py`: детектор цветовых событий в видео — HSV-порог, векторизованный трекинг блобов между кадрами (run-length через np.diff + union-find), счёт по сегментам с цветом-разделителем, ASCII-декод с `--expect` (exit 0 = префикс флага сошёлся). Смоук-тест: 5162 кадра, 429 объектов — точный счёт и декод за 27 с.
- `stego-workbench` §4 (видео): три проверенные механики — HUD-счётчики (`ffmpeg -sseof` + tesseract digits → chr), почти-чёрный текст (eq/threshold + OCR), цветовые события (`video_color_events.py`); принцип «геймплей = числа → ASCII → самопроверка префиксом»; визуальные аномалии подтверждает оператор (топ-5 кадров + один вопрос).
- `osint-workbench` §7: сенсорная петля с оператором — агент сам готовит артефакт (кроп/усиление/фрагмент), прикладывает к сообщению, задаёт один конкретный вопрос; ответ = факт в FACTS с источником «оператор, кадр N». Аудио: морзе/DTMF декодируй сам, опознание трека — оператор (Shazam/audiotag.info).
- CHANGELOG: восстановлена читаемая кодировка (файл был двойнокодирован), добавлены пропущенные записи 0.5.0/0.5.1.
